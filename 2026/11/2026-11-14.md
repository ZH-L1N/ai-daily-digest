## Developer Tools & Vibe Coding
• Cloudflare open-sources Kitesurf under Apache 2.0 — the agent-first browser engine runs entirely on Cloudflare Workers, parsing HTML, applying CSS, and executing JavaScript without a Chromium container; speaks Chrome DevTools Protocol (CDP) so Puppeteer and any existing CDP automation client connects unchanged; uses significantly less CPU and memory than headless Chrome for typical agentic tasks (screenshots, HTML extraction); built in Rust compiled to WebAssembly using Blitz, Stylo, and Boa; self-deployable to any Cloudflare Workers Paid account — gives agent developers a lightweight, self-hostable alternative to full Chromium that scales on demand across Cloudflare's global edge — https://blog.cloudflare.com/kitesurf-open-source

## Open-source models & agents
