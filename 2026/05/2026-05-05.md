# AI Daily Digest - 2026-05-05

## Anthropic

- **[Claude Code Gets Broader Plugin Support & MCP Fixes](https://releasebot.io/updates/anthropic)** - Today's Claude Code update (May 5) adds `.zip` plugin archive support via `--plugin-dir`, improved MCP handling (servers now show their tool count and flag zero-tool connections), and a refreshed `/model` picker that collapses duplicate Opus 4.7 entries. Sub-processes (Bash, hooks, MCP, LSP) no longer inherit `OTEL_*` environment variables, preventing OTEL-instrumented apps from picking up CLI telemetry unintentionally.

- **[Claude Opus 4.7 Generally Available](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic's latest model is a notable improvement over Opus 4.6 in advanced software engineering — particularly on the hardest tasks — with self-verification of outputs, and better vision supporting images up to ~3.75 megapixels. Alongside the model, Anthropic shipped a new `xhigh` effort level, task budgets in public beta, and `/ultrareview` in Claude Code (a dedicated review pass for Pro and Max users) that flags bugs a careful reviewer would catch.

- **[Claude Security in Public Beta for Enterprise](https://claude.com/claude-code-security)** - Built on Opus 4.7, Claude Security launched in public beta for Claude Enterprise customers, offering full-repo vulnerability scanning, confidence-rated findings with reproduction steps and patch recommendations, and Slack/Jira integration via webhooks. A multi-stage validation pipeline is designed to surface only high-signal findings, moving teams from detection to patching in a single session.

- **[Anthropic Forms Enterprise AI Services JV with Blackstone, H&F & Goldman Sachs](https://www.anthropic.com/news)** - Announced May 4, Anthropic is partnering with Blackstone, Hellman & Friedman, and Goldman Sachs to launch a new enterprise AI services company — a direct parallel to OpenAI's simultaneously announced $4B+ joint venture with TPG, Brookfield, Advent, and Bain Capital targeting business AI deployment.

## OpenAI

- **[Advanced Account Security Launches for ChatGPT & Codex](https://openai.com/news/)** - OpenAI launched an opt-in "Advanced Account Security" mode on May 4, adding phishing-resistant sign-in (passkeys/hardware keys), disabled email/SMS account recovery, shorter sessions, and login alerts. Protection extends to Codex, and members of Trusted Access for Cyber must enable it by June 1, 2026.

- **[GPT-5.5 & Codex Arrive on Amazon Bedrock](https://openai.com/index/openai-on-aws/)** - GPT-5.5 and GPT-5.4 are now available on Amazon Bedrock in limited preview (launched April 28), bringing OpenAI frontier models into AWS with unified IAM, PrivateLink, and CloudTrail controls. Codex is also live on Bedrock via CLI, desktop app, and VS Code extension, with usage counting toward AWS cloud commitments; Amazon Bedrock Managed Agents powered by OpenAI enables production-ready agentic deployment on AWS infrastructure.

- **[Codex Major Update — Persisted Goals & Richer TUI Controls](https://releasebot.io/updates/openai)** - A broad Codex release ships persisted `/goal` workflows with app-server APIs, runtime continuation, and TUI controls to create, pause, resume, and clear goals. The update also expands permission profiles, improves Windows and Bedrock support, and adds configurable TUI keymaps, cementing Codex as a full-session agentic coding tool.

## Google AI

- **[Deep Research & Deep Research Max Launch on Gemini 3.1 Pro](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google DeepMind released two next-generation autonomous research agents (April 21) built on Gemini 3.1 Pro. The faster "Deep Research" replaces the December preview with lower latency and higher quality; "Deep Research Max" uses extended test-time compute for maximum comprehensiveness — ideal for asynchronous nightly workflows like due-diligence reports. Both agents support MCP for private data sources, can blend web and internal data, and natively generate charts and infographics.

- **[Gemini 3.1 Pro Scores 85.9 on BrowseComp — 25+ Points Above Predecessor](https://siliconangle.com/2026/04/22/google-launches-ai-research-agents-powered-gemini-3-1-pro/)** - Google highlighted Gemini 3.1 Pro's substantially stronger BrowseComp performance (an OpenAI benchmark of 1,000+ online research tasks) compared to Gemini 3 Pro. Deep Research Max is designed for asynchronous, background research pipelines while Deep Research targets interactive, latency-sensitive user surfaces.

## Developer Tools & Vibe Coding

- **[SpaceX/xAI Secures $60B Acquisition Option for Cursor](https://www.cnbc.com/2026/04/21/spacex-says-it-can-buy-cursor-later-this-year-for-60-billion-or-pay-10-billion-for-our-work-together.html)** - SpaceX (which absorbed xAI in February) announced a $10B compute collaboration with Cursor — using the Colossus supercomputer to train Cursor's Composer models — plus an option to acquire Cursor outright for $60B later this year. The deal preempted a $2B funding round at a $50B valuation; Microsoft had examined an acquisition but passed. Analysts warn Anthropic or OpenAI could restrict model access to Cursor as happened with Windsurf during OpenAI acquisition talks.

- **[Amazon Q Developer IDE Plugins Sunset — Transition to Kiro by April 2027](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-whats-next-with-aws-2026-amazon-quick-openai-partnership-and-more-may-4-2026/)** - AWS announced Amazon Q Developer IDE plugins and paid subscriptions will reach end-of-support on April 30, 2027, with new signups blocked from May 15, 2026. Opus 4.6 will be removed from Q Developer Pro on May 29; the latest coding models (including Opus 4.7) are available exclusively on Kiro, AWS's next-generation AI-native IDE platform.

- **[Claude Code Auto Mode Extended to Max Plan Users](https://www.anthropic.com/news/claude-opus-4-7)** - Auto mode — where Claude autonomously makes tool-use and permission decisions for longer uninterrupted task runs — is now available to Max plan Claude Code users. Combined with the new `xhigh` effort level set as the new default in Claude Code for all plans, this enables more hands-off agentic coding workflows.
