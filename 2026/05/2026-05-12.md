# AI Daily Digest - 2026-05-12

## Anthropic
- **[Claude Opus 4.7 Launches with Enhanced Vision & Coding](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic released Claude Opus 4.7, offering substantially better vision (higher-resolution image processing), more creative and tasteful professional output, and a meaningful coding leap over Opus 4.6. The model is available via the Claude API, Amazon Bedrock, Google Vertex AI, and Microsoft Foundry at the same price as Opus 4.6 ($5/M input, $25/M output tokens). Opus 4.7 is also the first Claude model to ship with cyber capability safeguards developed under Project Glasswing.

- **[Anthropic Signs SpaceX Colossus Deal, Doubles Claude Code Rate Limits](https://www.aljazeera.com/economy/2026/5/6/spacex-backs-anthropic-with-data-centre-deal-amidst-musks-openai-lawsuit)** - Anthropic signed a deal to use all compute capacity at SpaceX's Colossus 1 data center in Memphis, Tennessee — over 220,000 NVIDIA GPUs and 300 megawatts of new capacity online within a month. Buoyed by the extra capacity, Anthropic doubled Claude Code's five-hour rate limits for Pro, Max, and Enterprise customers and removed peak-hour usage caps. The company also unveiled a "Dreaming" feature (research preview), allowing managed agents to review work between sessions and update memory files.

- **[Claude Platform on AWS Now Generally Available](https://releasebot.io/updates/anthropic)** - Anthropic launched the Claude Platform on AWS, giving AWS customers access to the full Claude API feature set — including the Messages API, Files API, Agent Skills, code execution, and tool use — with native AWS authentication, billing, and commitment retirement. Claude Opus 4.7, Sonnet 4.6, and Haiku 4.5 are available at launch, with new models shipping as they release. Anthropic operates the service with data processed outside the AWS boundary, differentiating it from Claude on Amazon Bedrock.

- **[Claude Security Enters Public Beta for Enterprise](https://releasebot.io/updates/anthropic/claude)** - Claude Security is now in public beta for Claude Enterprise customers, bringing AI-powered code vulnerability scanning and proposed fixes powered by Opus 4.7. Features include scheduled and targeted scans, triage tracking, and workflow integrations, with early adopters like DoorDash and Supercell already reporting high-quality, actionable findings integrated directly into developer workflows.

## OpenAI
- **[OpenAI Launches $4B+ Deployment Company, Acquires Tomoro](https://openai.com/index/openai-launches-the-deployment-company/)** - OpenAI launched the OpenAI Deployment Company (DeployCo), a new $4B+ majority-owned venture backed by 19 global firms including TPG (lead), Goldman Sachs, SoftBank, Bain Capital, and Brookfield. Modeled on Palantir's forward-deployed-engineer playbook, it embeds specialized AI engineers directly inside enterprises to move from pilot to production. To staff it immediately, OpenAI acquired Tomoro, a UK-based AI consulting firm with ~150 engineers and clients including Mattel, Tesco, Virgin Atlantic, and Red Bull.

- **[Running Codex Safely: OpenAI Publishes Safety Blueprint](https://openai.com/index/running-codex-safely/)** - OpenAI published its internal approach to deploying Codex safely within its own engineering organization. The framework covers sandboxed execution environments, tiered approval workflows (including an "auto-review" sub-agent for low-risk actions), strict network policies that disable open-ended outbound access, and agent-native telemetry for auditing. The post signals that enterprise-grade governance — not model benchmarks — is becoming the next key competitive frontier for coding agents.

- **[GPT-5.5 Instant Becomes ChatGPT's New Default Model](https://techcrunch.com/2026/05/05/openai-releases-gpt-5-5-instant-a-new-default-model-for-chatgpt/)** - OpenAI replaced GPT-5.3 Instant with GPT-5.5 Instant as the default ChatGPT model, touting reduced hallucination in sensitive domains (law, medicine, finance) and improved AIME math benchmark scores (81.2 vs. 65.4). The model also gains enhanced personalization by referencing past chats, saved files, and connected Gmail, with memory sources now visible and editable by users across all plans.

- **[Three New Realtime Voice Models Land in the API](https://releasebot.io/updates/openai)** - OpenAI released three new audio models for developers: GPT-Realtime-2 (GPT-5-class reasoning for live voice), GPT-Realtime-Translate (real-time multilingual speech translation across 70+ input and 13 output languages), and GPT-Realtime-Whisper (streaming speech-to-text). The trio is designed to unlock a new class of voice applications that feel natural, respond intelligently, and take action in real time.

## Google AI
- **[The Android Show: I/O Edition Streams Today (May 12)](https://io.google/2026/)** - Google is hosting The Android Show: I/O Edition on May 12 at 10AM PT, a dedicated pre-I/O showcase promising "one of the biggest years for Android yet." Expect announcements around Android 17 features, deeper Gemini AI integrations across the OS, Android XR mixed-reality updates, and possible details on the rumored Aluminium OS PC platform. Google I/O 2026 proper follows on May 19–20 at the Shoreline Amphitheatre.

- **[Gemini 3 Deep Think Gets Major Science-Focused Upgrade](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a major upgrade to Gemini 3 Deep Think, its specialized reasoning mode for science, research, and engineering. The updated model achieves gold-medal-level results on the 2025 International Physics and Chemistry Olympiad written sections and can turn sketches into 3D-printable files. It is now available to Google AI Ultra subscribers in the Gemini app, with API early access opening to select researchers and enterprises.

- **[Google Preps "AI Ultra Lite" Subscription Tier](https://9to5google.com/2026/05/05/google-ai-ultra-lite-gemini-usage-limits/)** - Code spotted in the Gemini macOS app reveals Google is preparing a new "AI Ultra Lite" subscription (codename "Neon") to slot between its $20 AI Pro and $250 AI Ultra plans. The tier appears designed to address a broader token crunch as AI agent and coding workloads push usage limits, and is expected to be priced in the $50–$150 range. Exact features and launch date have not yet been confirmed.

- **["Remy" — Google's 24/7 AI Agent Takes Shape Ahead of I/O](https://tech.yahoo.com/ai/gemini/articles/google-wants-evolve-gemini-full-103105998.html)** - Internal Google documents reveal an always-on AI agent project called "Remy," designed to act as a true 24/7 assistant that takes actions on users' behalf across third-party services. Unlike the current Gemini chatbot, Remy focuses on running tasks in the background — managing ongoing tasks, scheduled actions, and jobs waiting for user input — pointing toward Gemini's evolution from conversational AI to autonomous agent ahead of Google I/O.

## Developer Tools & Vibe Coding
- **[SpaceX Secures $60B Option to Acquire Cursor](https://techcrunch.com/2026/04/21/spacex-is-working-with-cursor-and-has-an-option-to-buy-the-startup-for-60-billion/)** - SpaceX (now merged with xAI) pre-empted Cursor's planned $2B fundraise with a landmark deal: a $10B collaboration agreement to build "the world's best coding and knowledge work AI," plus an option to acquire Cursor for $60 billion by year-end (or pay the $10B as a breakup fee). The deal gives Cursor access to SpaceX's Colossus training supercomputer, while giving SpaceX a foothold in the most lucrative AI application category ahead of its planned summer IPO.

- **[OpenAI Codex Now Native in Cursor and VS Code](https://developers.openai.com/codex/changelog)** - GPT-5.3-Codex is now available natively inside Cursor and VS Code, expanding Codex's reach beyond the dedicated Codex app. This is the first Codex model treated as a high-security capability under OpenAI's Preparedness Framework, with API access rolling out to a small set of customers in a phased release. The expanded distribution intensifies competition with Anthropic's Claude Code and GitHub Copilot at the IDE level.

- **[Amazon Q Developer Announces End-of-Support, Transitions to Kiro](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-whats-next-with-aws-2026-amazon-quick-openai-partnership-and-more-may-4-2026/)** - AWS announced that Amazon Q Developer IDE plugins and paid subscriptions will reach end-of-support on April 30, 2027, giving customers 12 months to transition to Kiro — Amazon's next-generation AI coding environment. New Q Developer signups will be blocked starting May 15, 2026, and the latest coding models (including Claude Opus 4.7) will be exclusively available on Kiro going forward.
