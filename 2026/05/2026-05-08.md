# AI Daily Digest - 2026-05-08

## Anthropic

- **[Claude Stays Ad-Free — Anthropic Explains Why](https://www.anthropic.com/news)** - Anthropic published a post declaring Claude will remain permanently ad-free, arguing that advertising incentives are fundamentally incompatible with a genuinely helpful AI assistant. The announcement directly contrasts with OpenAI's move into advertising and appears designed to reinforce trust with enterprise and power users evaluating which platform to commit to long-term.

- **[Claude Code Bug Fixes: VS Code on Windows & Mantle Auth](https://releasebot.io/updates/anthropic)** - Anthropic pushed targeted fixes to Claude Code addressing two developer pain points: VS Code extension activation failures on Windows (caused by a hardcoded build path in the bundled SDK's `createRequire` polyfill) and Mantle endpoint authentication failures due to a missing `x-api-key` header. These follow a broader wave of Claude Code updates including a new `--plugin-url` flag for loading plugins from URL, a `CLAUDE_CODE_FORCE_SYNC_OUTPUT` env var for non-standard terminals, and improvements to sessions, OAuth, MCP, and cache handling.

- **["Code w/ Claude" Event Highlights: Remote Agents, CI Auto-Fix, Code Review](https://simonwillison.net/2026/May/6/code-w-claude-2026/)** - At Anthropic's developer event on May 6, the company showcased Remote Agents (controlling your laptop from a phone via Claude Code), a new Code Review tool already used by every team at Anthropic internally, and a CI auto-fix feature that automatically files PRs with fixes. Both the IDE and Desktop app are built on the same Claude Agent SDK that external developers can use, and Shopify and Mercado Libre (23,000 engineers) were cited as key customers targeting "90% autonomous coding by Q3."

## OpenAI

- **[OpenAI Launches GPT-Realtime-2 for Production Voice Agents](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/)** - OpenAI shipped GPT-Realtime-2, its most capable voice API model yet, designed for live production voice agents. Key new capabilities include parallel tool calls with audible transparency ("looking that up now"), preamble phrases so users know the model is working, and stronger recovery behavior (graceful error messaging rather than silent failure). GPT-Realtime-2 scores 15.2% higher on Big Bench Audio and 13.8% higher on Audio MultiChallenge than its predecessor, GPT-Realtime-1.5.

- **[ChatGPT Ads Go Global — Expanding to UK, Brazil, Japan, South Korea & Mexico](https://digiday.com/media-buying/expand-thoughtfully-openai-offers-chatgpt-ads-to-new-markets-including-the-u-k-brazil-and-japan/)** - One day after opening its self-serve Ads Manager to all US advertisers with new CPC bidding, OpenAI announced it is expanding the ChatGPT ads pilot to the UK, Brazil, Japan, South Korea, and Mexico. The program, which launched in the US in February, already averages ~$109M/month in ad spend with early signals of no impact on consumer trust metrics and low ad dismissal rates. Ads remain only for Free and Go tier users; Plus, Pro, Business, and Enterprise tiers stay ad-free.

- **[Trusted Contact & Advanced Account Security Land in ChatGPT](https://releasebot.io/updates/openai)** - OpenAI introduced Trusted Contact — a new safety feature in ChatGPT — alongside Advanced Account Security, which adds phishing-resistant sign-in, stricter account recovery (disabling email/SMS recovery in favor of passkeys and security keys), shorter session windows, and login alerts. Starting June 1, Trusted Access for Cyber members must enable Advanced Account Security or attest to SSO-based phishing-resistant authentication.

## Google AI

- **[Google Internally Testing "Remy" — A 24/7 Personal AI Agent on Gemini](https://letsdatascience.com/news/google-tests-gemini-powered-remy-personal-ai-agent-183f74c5)** - Business Insider reports that Google is dogfooding an AI agent codenamed "Remy" inside a staff-only Gemini app build. Internal documents describe it as a "24/7 personal agent for work, school, and daily life" that takes actions on your behalf rather than just answering questions. Decompiled app strings show integrations with Gmail, Calendar, Drive, Keep, GitHub, WhatsApp, Spotify, and Google Photos. No public launch date has been set, though Google I/O on May 19–20 is the likely reveal window.

- **[Google Readies "AI Ultra Lite" Mid-Tier Gemini Subscription](https://9to5google.com/2026/05/05/google-ai-ultra-lite-gemini-usage-limits/)** - Spotted in the latest Gemini macOS app update, a new codename "Neon" subscription tier branded "Google AI Ultra Lite" is emerging between the existing AI Pro and AI Ultra ($250/month) plans. No price has been confirmed, but analysts expect it to land near the $100/month mark to compete with Anthropic's Max and OpenAI's Pro tiers. Google is also adding a visual usage indicator showing token budgets and five-hour session limits, matching the experience Anthropic already provides for Claude subscribers.

- **[Gemini Embedding 2 Reaches General Availability](https://releasebot.io/updates/google/gemini)** - Google announced the general availability of Gemini Embedding 2 via both the Gemini API and Vertex AI. The omnimodal embedding model maps text, images, video, audio, and PDFs into a single unified semantic space without lossy intermediate steps like OCR or transcription, topping retrieval benchmarks across 100+ languages. The GA release signals it is now ready for production workloads.

## Developer Tools & Vibe Coding

- **[Amazon Q Developer End-of-Support Confirmed: Transition to Kiro by April 2027](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-whats-next-with-aws-2026-amazon-quick-openai-partnership-and-more-may-4-2026/)** - AWS confirmed that Amazon Q Developer IDE plugins and paid subscriptions will reach end-of-support on April 30, 2027, with new signups blocked starting May 15, 2026. Customers are directed to migrate to Kiro, Amazon's next-generation AI IDE. Notably, Opus 4.7 will be available exclusively on Kiro, and the latest Claude coding models will not be added to Q Developer Pro after May 29. Q Developer integrations in the AWS Console, Slack, and Teams remain unaffected.

- **[AI Coding Market Snapshot: 74% Dev Adoption, Cursor & Claude Code Tied at 18%](https://neuronad.com/cursor-vs-windsurf/)** - According to JetBrains' January 2026 developer survey, 74% of developers worldwide now use at least one specialized AI coding tool. GitHub Copilot leads at 29% workplace adoption, while Cursor and Claude Code are tied at 18%, and Windsurf sits at ~8% — but all three challengers are growing faster than Copilot on a percentage basis. The $7B+ market is converging on the "agent" paradigm: repo-aware, autonomous multi-file editing rather than simple autocomplete, with Windsurf's Cascade (powered by Cognition/Devin architecture) and Claude Code's 1M-token context window competing as the top choices for long-horizon agentic coding.
