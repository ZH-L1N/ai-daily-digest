# AI Daily Digest - 2026-05-03

## Anthropic

- **[Claude Security Launches in Public Beta for Enterprise](https://claude.com/blog/claude-security-public-beta)** - Anthropic opened Claude Security (formerly Claude Code Security) to all Enterprise customers on May 1, powered by Claude Opus 4.7. The tool scans entire codebases for vulnerabilities by tracing data flows across files rather than relying on static pattern matching, and generates verified patches directly applicable within a Claude Code session. Major security vendors — CrowdStrike, Microsoft Security, Palo Alto Networks, SentinelOne, and Wiz — are embedding Opus 4.7 into their platforms, while Accenture, Deloitte, and PwC are supporting enterprise deployments.

- **[Anthropic Investigates Unauthorized Access to Claude Mythos](https://www.engadget.com/ai/anthropic-is-investigating-unauthorized-access-of-its-mythos-cybersecurity-tool-091017168.html)** - Anthropic confirmed it is investigating a report of unauthorized access to its restricted Claude Mythos Preview model, which can autonomously discover and exploit zero-day vulnerabilities in every major OS and browser. A Discord-based group gained access on the day of the announcement through a third-party contractor portal by making an educated guess about the model's URL structure. Anthropic said there is no evidence that systems outside the third-party vendor environment were impacted, but the incident raises questions about access controls around the high-stakes model.

- **[Claude Opus 4.7 Now Generally Available](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic's latest flagship model, Claude Opus 4.7, is available across the API, Claude products, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry at the same $5/$25 per MTok pricing as Opus 4.6. Key upgrades include a native 1M token context window (no beta header required), high-resolution image support (up to 2576px/3.75MP), 128k max output tokens, and a step-change improvement in agentic coding — early testers report 13% higher resolution rates over Opus 4.6 on a 93-task coding benchmark.

- **[Claude Code Broad Update: Project Purge, Bedrock Tiers, and OpenTelemetry](https://releasebot.io/updates/anthropic/claude-code)** - Claude Code shipped a major release adding `claude project purge [path]` to delete all project state (transcripts, tasks, file history) with dry-run and interactive modes, a new `ANTHROPIC_BEDROCK_SERVICE_TIER` environment variable for Bedrock tier selection (default/flex/priority), and PR URL pasting in `/resume` search for GitHub, GitLab, and Bitbucket. OpenTelemetry gains new at-mention log events and numeric attributes, while Windows received critical fixes for drive-letter path anchoring and environment file handling. Also fixed: Opus 4.7 sessions erroneously computing context percentages against a 200K window instead of its native 1M.

- **[Pentagon Signs AI Deals with Seven Companies, Excludes Anthropic](https://www.cnn.com/2026/05/01/tech/pentagon-ai-anthropic)** - The Department of Defense announced AI agreements with SpaceX, OpenAI, Google, Microsoft, Nvidia, Amazon Web Services, and Reflection for use on classified networks — but not Anthropic. The Trump administration blacklisted Anthropic after the company refused to allow Claude to be used for autonomous weapons and mass surveillance without safety guardrails. Anthropic sued and won a federal injunction last month, and the White House has since reopened talks after the unveiling of Claude Mythos.

## OpenAI

- **[OpenAI Models, Codex, and Managed Agents Come to AWS](https://openai.com/index/openai-on-aws/)** - Following the revised Microsoft-OpenAI partnership that ended exclusivity, OpenAI launched GPT-5.5, its Codex coding agent, and Amazon Bedrock Managed Agents in limited preview on AWS. Enterprise customers can now build with OpenAI models inside AWS using existing security controls and procurement processes; usage also counts toward AWS committed spend. More than 4 million people now use Codex weekly, and the expansion makes Codex multi-cloud for the first time.

- **[GPT-5.5 Now Available in ChatGPT, API, and Codex](https://openai.com/index/introducing-gpt-5-5/)** - GPT-5.5 — OpenAI's "smartest and most intuitive" model to date — is rolling out to Plus, Pro, Business, and Enterprise users in ChatGPT and Codex. The model excels at agentic coding, computer use, and knowledge work, matching GPT-5.4 per-token latency while performing at significantly higher intelligence. It is also more token-efficient on Codex tasks than its predecessor, and GPT-5.5 Pro with extended reasoning is available for Pro/Business/Enterprise plans.

- **[OpenAI Introduces Advanced Account Security for ChatGPT](https://releasebot.io/updates/openai/chatgpt)** - OpenAI launched Advanced Account Security on April 30, an opt-in protection layer that enables phishing-resistant passkey-based sign-in, disables email/SMS account recovery in favor of backup passkeys and recovery keys, shortens session durations, and sends login alerts. The feature extends protections into Codex, and members of the Trusted Access for Cyber program will be required to enable it starting June 1, 2026.

- **[ChatGPT Gets Fast Answers and Model-Picker Improvements](https://releasebot.io/updates/openai/chatgpt)** - ChatGPT rolled out "Fast Answers" globally — a mode for high-confidence, common factual queries that responds without consulting memory or past chats, available on web, iOS, and Android. Separately, model selection moved into the composer UI and thinking-effort controls were integrated into the model picker, making it easier to switch models and adjust reasoning depth before sending a prompt. These updates are live for Plus, Pro, and Business plans on web.

## Google AI

- **[Google Launches Deep Research and Deep Research Max on Gemini 3.1 Pro](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google DeepMind launched two autonomous research agents in public preview via the Gemini API. Both are built on Gemini 3.1 Pro, support MCP for private data sources, and generate native charts/infographics inline. Deep Research Max runs ~160 searches per task, achieves 93.3% on DeepSearchQA (up from 66.1% in December) and 54.6% on Humanity's Last Exam, and is designed for asynchronous overnight workflows; the standard Deep Research agent prioritizes low-latency interactive use. Google is partnering with FactSet, S&P Global, and PitchBook to build financial data MCP integrations.

- **[Gemini Rolling Out to Millions of Cars with Google Built-In](https://techcrunch.com/2026/04/30/googles-gemini-ai-assistant-is-hitting-the-road-in-millions-of-vehicles/)** - Google announced that Gemini is rolling out to vehicles with Google built-in, starting in the US with English-language support. General Motors simultaneously confirmed Gemini is coming to approximately 4 million vehicles from model year 2022 and newer across Cadillac, Chevrolet, Buick, and GMC. Drivers get conversational access via voice, touchscreen, or steering wheel controls, with future integrations planned for Gmail, Google Calendar, and Google Home.

- **[Gemini API: Flash TTS Preview, Updated Robotics Model, and Deprecations](https://ai.google.dev/gemini-api/docs/changelog)** - Google added Gemini 3.1 Flash TTS Preview to the Gemini API — a cost-efficient, expressive, steerable text-to-speech model. The update also shipped an updated robotics model (gemini-robotics-er-1.6-preview) with improved instrument reading and spatial/physical reasoning. The previous robotics preview (er-1.5) was deprecated effective April 30, 2026.

## Developer Tools & Vibe Coding

- **[SpaceX Partners with Cursor, Holds $60B Acquisition Option](https://techcrunch.com/2026/04/21/spacex-is-working-with-cursor-and-has-an-option-to-buy-the-startup-for-60-billion/)** - SpaceX (which already absorbed xAI in February) announced a landmark deal with AI coding startup Cursor: a $10B collaboration to build next-generation "coding and knowledge work AI," pairing Cursor's Composer model with SpaceX's Colossus supercomputer (~1 million H100 equivalent). SpaceX also holds an exclusive option to acquire Cursor outright for $60B by end of 2026, with a $10B breakup fee if it declines. Investors say the deal positions SpaceX to challenge Anthropic and OpenAI in the developer tools market by eliminating Cursor's reliance on third-party model APIs.

- **[GitHub Copilot Moving to Usage-Based Billing on June 1](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)** - GitHub announced all Copilot plans will switch from premium-request-unit (PRU) billing to token-based GitHub AI Credits on June 1, 2026 (1 AI Credit = $0.01 USD). Base subscription prices are unchanged (Pro $10/mo, Pro+ $39/mo, Business $19/user/mo), but heavy agentic users will likely see higher costs as long-running sessions consume more tokens. Code completions and Next Edit Suggestions remain unlimited for all paid plans. A preview bill dashboard is launching in early May so users can project costs before the switch.

- **[Cursor Ships TypeScript SDK with Sandboxed Cloud VMs and Subagents](https://singhajit.com/dev-weekly/2026/apr-27-may-3/)** - Cursor released a TypeScript SDK that exposes its agent runtime with sandboxed cloud VMs and subagent support, opening up Cursor's agentic infrastructure as a programmable platform. The same week saw Warp open-source its agentic IDE, Sentry launch the Seer Agent (a plain-English AI debugger), and OpenAI publish Symphony — an open-source specification for coding agent orchestration. These releases collectively signal a maturing of the AI coding-agent ecosystem beyond the IDE layer.
