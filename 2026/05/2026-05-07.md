# AI Daily Digest - 2026-05-07

## Anthropic

- **[Anthropic Eyes Consumer Market with Claude Pivot](https://www.bloomberg.com/news/articles/2026-05-07/anthropic-is-making-claude-chatbot-more-appealing-to-consumers)** - Anthropic is expanding beyond its enterprise-first strategy, tasking employees since late last year with improving Claude's handling of personal queries like health, travel, and recipes. The move aims to capitalize on recent consumer inroads while broadening the user base well beyond business clients.

- **[Anthropic Signs Compute Deal with SpaceX](https://www.bloomberg.com/news/articles/2026-05-06/anthropic-inks-computing-deal-with-spacex-to-meet-ai-demand)** - Anthropic has inked a new compute partnership with SpaceX to substantially increase capacity and meet surging demand for Claude. The deal accompanies raised usage limits across Claude products and signals Anthropic's aggressive infrastructure buildout amid 80× growth—far exceeding their internal 10× projection.

- **[Anthropic Deepens Wall Street Push: Finance Agents, MS 365 Integration & Moody's Partnership](https://fortune.com/2026/05/05/anthropic-wall-street-financial-services-agents-jamie-dimon/)** - At an invite-only New York financial services briefing on May 5, Anthropic launched 10 ready-to-run AI agent templates for banking workflows (pitchbooks, KYC screening, month-end close), rolled out Claude add-ins for Excel, PowerPoint, and Word (now GA), and announced a marquee Moody's partnership enabling credit risk analysis on 600M+ companies. Financial institutions now make up roughly 40% of Anthropic's top 50 enterprise customers.

- **[Claude Opus 4.7 Now Generally Available](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic's latest flagship brings a 13% coding benchmark lift over Opus 4.6 (including solving tasks Opus 4.6 and Sonnet 4.6 could not), 3×+ higher image resolution support (up to 3.75MP), a new `xhigh` effort level, and a new `/ultrareview` slash command in Claude Code for deep PR review. Available on the API, Amazon Bedrock, Google Cloud's Vertex AI, and Microsoft Foundry at $5/M input and $25/M output tokens—same price as Opus 4.6.

## OpenAI

- **[GPT-5.5 Instant Becomes ChatGPT's New Default Model](https://openai.com/index/gpt-5-5-instant/)** - OpenAI replaced GPT-5.3 Instant with GPT-5.5 Instant as the default ChatGPT model for all users on May 5, delivering 52.5% fewer hallucinations on high-stakes prompts (medicine, law, finance), 37.3% fewer factual errors on flagged conversations, and ~30% more concise responses. A new "Memory Sources" feature lets Plus and Pro users draw personalized context from past chats, uploaded files, and Gmail, with visibility and deletion controls.

- **[ChatGPT Futures: Class of 2026 Announced](https://openai.com/news/)** - OpenAI launched its ChatGPT Futures program targeting the Class of 2026, signaling a push to embed ChatGPT deeper into academic and early-career workflows. The company also introduced Advanced Account Security with phishing-resistant sign-in options, shorter sessions, login alerts, and tighter recovery controls—extending protections to Codex users as well.

- **[OpenAI Models and Codex Come to Amazon Bedrock](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-whats-next-with-aws-2026-amazon-quick-openai-partnership-and-more-may-4-2026/)** - OpenAI's latest models (GPT-5.5 and GPT-5.4) are now accessible via Amazon Bedrock APIs in limited preview, with Codex also landing on Bedrock via CLI, desktop app, and a VS Code extension. Amazon Bedrock Managed Agents powered by OpenAI enables production-ready OpenAI agent workflows inside existing AWS environments.

## Google AI

- **[Deep Research & Deep Research Max Launch on Gemini API](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google launched two autonomous research agents built on Gemini 3.1 Pro: speed-optimized Deep Research and comprehensiveness-focused Deep Research Max (93.3% on DeepSearchQA, 54.6% on Humanity's Last Exam). Both support MCP for private data integration (FactSet, PitchBook, etc.), native chart and infographic generation, and real-time streaming of intermediate reasoning steps—available via Gemini API in public preview.

- **[Gemini 3 Deep Think Gets Major Science Upgrade](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a substantial upgrade to Gemini 3 Deep Think, achieving gold-medal-level results on the written sections of the 2025 International Physics and Chemistry Olympiads and 50.5% on CMT-Benchmark for advanced theoretical physics. The upgraded Deep Think is now live for Google AI Ultra subscribers in the Gemini app, with early-access API availability for researchers and enterprises.

- **[Google DeepMind UK Workers Push to Unionize Over Pentagon AI Deal](https://www.outlookbusiness.com/news/deepmind-workers-revolt-against-googles-pentagon-partnership)** - Following Google's deal with the US Department of Defense granting Gemini AI access to classified military networks "for any lawful purpose," DeepMind UK employees have sought recognition from Unite and the Communications Workers Union. The move reflects broader unease within the AI research community about military AI applications, though Google says no formal vote has taken place.

## Developer Tools & Vibe Coding

- **[SpaceX Secures $60B Option to Acquire Cursor, Pays $10B Collaboration Fee](https://techcrunch.com/2026/04/22/how-spacex-preempted-a-2b-fundraise-with-a-60b-buyout-offer/)** - SpaceX (merged with xAI) pre-empted Cursor's planned $2B fundraise by striking a deal that pairs $10B in collaboration funding with a standing $60B acquisition option, deferred until after SpaceX's planned summer IPO. Cursor—now at $2B ARR and used by 64% of Fortune 500 companies—will pair its developer distribution with SpaceX's Colossus supercomputer to build next-generation coding and knowledge-work AI.

- **[GitHub Copilot CLI v1.0.43: Auto Mode Routing + Critical RCE Security Patch](https://github.com/github/copilot-cli/releases)** - The May 6 release of GitHub Copilot CLI adds server-side model routing for Auto mode for smarter real-time model selection, a username toggle in the statusline, and patches a critical remote code execution vulnerability (GHSA-9ccr-r5hg-74gf) triggered by malicious bare repositories nested in a project. GitHub also tightened individual plan usage limits and temporarily paused new signups, citing runaway token consumption from agentic and parallelized workflows.

- **[Claude Code Adds Bedrock Tier Selection, /ultrareview, and OpenTelemetry Improvements](https://releasebot.io/updates/anthropic)** - Recent Claude Code updates add Bedrock service tier selection via `ANTHROPIC_BEDROCK_SERVICE_TIER` (default, flex, or priority), the new `/ultrareview` command offering deep PR review sessions (Pro and Max users get three free to start), expanded OpenTelemetry numeric attribute logging, and improved MCP handling for connectors hidden by duplicate server URLs. Claude Code continues to expand its footprint as a top terminal-native agentic coding environment.
