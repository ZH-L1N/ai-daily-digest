# AI Daily Digest - 2026-05-14

## Anthropic

- **[Claude Opus 4.7 Now Available](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic has released Claude Opus 4.7, its most capable broadly available model to date, featuring substantially improved vision, cleaner code output (described by testers as "the cleanest jump we've seen since the move from Sonnet 3.7 to the Claude 4 series"), and 98.5% on XBOW's visual-acuity benchmark vs. 54.5% for Opus 4.6. The model is priced at $5/M input and $25/M output tokens and is available across all Claude products, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry.

- **[Claude for Small Business Launches](https://finance.yahoo.com/news/anthropic-debuts-claude-for-small-business-as-it-continues-its-enterprise-software-push-160500355.html)** - Anthropic launched Claude for Small Business, a toggle-install package of connectors and ready-to-run workflows for the Claude desktop app that integrates with Intuit QuickBooks, PayPal, HubSpot, Canva, DocuSign, Google Workspace, and Microsoft 365. It can automate tasks like payroll planning, closing the month, running sales campaigns, and chasing invoices — and comes with a free 14-lecture AI fluency course for small business owners.

- **[Claude Platform on AWS Goes GA](https://releasebot.io/updates/anthropic)** - Anthropic's Claude Platform on AWS is now generally available, bringing the full Claude API feature set — including Managed Agents, Agent Skills, code execution, the Files API, and the Message Batches API — to AWS customers with native AWS authentication and billing. Models available at launch include Claude Opus 4.7, Sonnet 4.6, and Haiku 4.5, with new models shipping as they release.

- **[SAP & Anthropic Expand Partnership at SAP Sapphire](https://news.sap.com/2026/05/sap-anthropic-to-bring-claude-sap-business-ai-platform/)** - SAP and Anthropic announced at SAP Sapphire a major expansion making Claude a primary reasoning and agentic capability embedded across SAP's AI-enabled solution portfolio, powered by Joule and Joule agents. The collaboration will bring Claude's agentic capabilities to the newly announced SAP Business AI Platform, enabling agents that can take real action for hundreds of thousands of SAP customers across finance, HR, procurement, and supply chain.

- **[Code w/ Claude Event: Claude Code Gets Major Upgrades](https://simonwillison.net/2026/May/6/code-w-claude-2026/)** - At Anthropic's "Code w/ Claude" developer event, the company announced doubled rate limits for Claude Code and the API for Pro, Max, and Enterprise customers, and is partnering with SpaceX to use all capacity of the Colossus data center. New Claude Code features include multi-agent orchestration (public beta), remote agents (control your laptop from your phone), CI auto-fix (automatic PR fixes), Code Review (used by every team at Anthropic), and a "Dreaming" research preview that lets Claude inspect previous sessions to self-improve overnight.

## OpenAI

- **[OpenAI Deployment Company Launches, Acquires Tomoro](https://openai.com/index/openai-launches-the-deployment-company/)** - OpenAI launched the OpenAI Deployment Company (DeployCo), a new organization designed to embed specialized Forward Deployed Engineers into businesses tackling complex problems with AI — helping organizations redesign infrastructure and critical workflows around frontier AI. The company simultaneously announced it agreed to acquire Tomoro to supply experienced FDEs from day one.

- **[GPT-5.5 Instant Is ChatGPT's New Default Model](https://releasebot.io/updates/openai)** - OpenAI updated ChatGPT's default model for all users to GPT-5.5 Instant, which brings smarter and more accurate answers with better personalization drawn from past chats, files, and Gmail. Memory sources are rolling out across all ChatGPT consumer plans on web and soon on mobile, offering clearer visibility and control over how context shapes responses.

- **[OpenAI Publishes Parameter Golf Lessons](https://openai.com/index/what-parameter-golf-taught-us/)** - OpenAI published a retrospective on its Parameter Golf challenge, an 8-week open ML competition that drew 2,000+ submissions from 1,000+ participants who had to train the best language model fitting within a 16 MB artifact in under 10 minutes on 8×H100s. A major finding was that the widespread use of coding agents dramatically lowered the barrier to entry, though it also blurred the line between creative submissions and incremental remixes of existing top-scoring approaches.

- **[OpenAI Confirms No User Data Breached in Supply-Chain Attack](https://www.usnews.com/news/top-news/articles/2026-05-14/openai-says-no-user-data-breached-after-security-issue-with-open-source-library)** - OpenAI said on May 14 it found no evidence that user data was accessed following a security issue involving a supply-chain attack on TanStack npm, an open-source library. The company investigated the incident and confirmed user data remained secure.

- **[New Realtime Voice Models in the API](https://releasebot.io/updates/openai)** - OpenAI introduced three new audio models in the API: GPT-Realtime-2 (GPT-5-class reasoning for live voice), GPT-Realtime-Translate (live speech translation across 70+ input languages to 13 output languages), and GPT-Realtime-Whisper (streaming real-time transcription). GPT-Realtime-2 improved call success rate by 26 points on Zillow's hardest adversarial benchmark and showed stronger Fair Housing compliance.

## Google AI

- **[Android Show: Gemini Intelligence, Googlebooks & Magic Pointer](https://techcrunch.com/2026/05/12/everything-google-announced-at-its-android-show-from-googlebooks-to-vibe-coded-widgets/)** - At its pre-I/O Android Show on May 12, Google unveiled Gemini Intelligence — a suite of proactive, agentic AI features for Android that can move across apps, understand screen context, and complete multi-step tasks like building shopping carts or booking reservations. The features will first roll out to Samsung Galaxy and Google Pixel phones this summer, and extend to Wear OS, Android Auto, Android XR, and laptops later this year.

- **[Googlebooks: New AI-First Laptop Category Announced](https://techcrunch.com/2026/05/12/everything-google-announced-at-its-android-show-from-googlebooks-to-vibe-coded-widgets/)** - Google announced Googlebooks, a new line of Gemini-native laptops built with partners including Acer, ASUS, Dell, HP, and Lenovo, launching this fall. Googlebooks will ship with "Magic Pointer" (a DeepMind-powered AI cursor), compatibility with Android phones for running phone apps directly on the laptop, and a "Create My Widget" feature letting users vibe-code custom home-screen widgets using natural language.

- **[DeepMind Unveils AI-Enabled Mouse Pointer Powered by Gemini](https://deepmind.google/blog/ai-pointer/)** - Google DeepMind published research on an experimental AI-enabled pointer that understands the semantic context of on-screen elements — replacing text-heavy prompts with interactions like pointing at a building image and saying "Show me directions." Two live demos (image editing and map search) are available in Google AI Studio today, and Gemini in Chrome is rolling out the ability to use your pointer to ask about any part of a webpage.

- **[Google I/O 2026 Preview: Gemini 4 Expected Next Week](https://sources.news/p/google-about-to-release-new-gemini)** - Google I/O 2026 kicks off May 19–20, where sources say Google plans to announce a new Gemini model that "will land roughly in the class of GPT-5.5." Expectations also include Android 17, Android XR glasses preview, and more Gemini agentic capability announcements at the flagship developer conference.

## Developer Tools & Vibe Coding

- **[GitHub Copilot Moves to Usage-Based Billing on June 1](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)** - GitHub announced all Copilot plans will transition from Premium Request Units (PRUs) to token-based GitHub AI Credits on June 1, 2026. Base subscription prices are unchanged (Pro at $10/mo, Business at $19/user/mo), but agentic workflows, Copilot Chat, and code review will now consume credits based on actual token usage — a change that concerns heavy users who may see effective costs rise. A billing preview tool is available now on the GitHub Billing Overview page.

- **[SpaceX Places $60B Buyout Option on Cursor](https://press.airstreet.com/p/state-of-ai-may-2026)** - In a major vibe-coding industry move, SpaceX pre-empted Cursor's planned $2B fundraise with a standing $60B buyout option (or $10B in exchange for an AI collaboration agreement), with the acquisition deferred until after SpaceX's planned summer IPO. Cursor, the AI-native VS Code fork from Anysphere, hit $2B ARR in March 2026 and is tied with Claude Code at 18% workplace adoption per JetBrains' January developer survey.

- **[Claude Code "Dreaming" Enables Overnight Self-Improvement](https://simonwillison.net/2026/May/6/code-w-claude-2026/)** - Among the most novel Claude Code features announced at Code w/ Claude, "Dreaming" (research preview) allows Claude to inspect its previous sessions overnight and self-improve by creating new memory files like playbooks. Combined with multi-agent orchestration (Commander, Detector, Navigator agents) and the new Outcomes feature (both in public beta), Claude Code is being positioned for increasingly autonomous, long-horizon software engineering tasks.

- **[ChatGPT for Excel & Google Sheets Now Available Globally for Business](https://releasebot.io/updates/openai)** - OpenAI rolled out ChatGPT for Excel and Google Sheets globally for ChatGPT Business, providing a spreadsheet-native sidebar for building, cleaning, updating, and explaining workbooks. It supports Skills and apps connected to a user's ChatGPT account, with a free preview running through June 2, 2026 for Business customers.
