# AI Daily Digest - 2026-05-10

## Anthropic

- **[Claude Security Public Beta Launches for Enterprise](https://www.anthropic.com/news)** - Anthropic opened Claude Security (formerly Claude Code Security) to public beta for Claude Enterprise customers. Powered by Opus 4.7, the tool scans entire codebases for vulnerabilities by reasoning about data flows and component interactions—the way a security researcher would—rather than relying on pattern-matching. Each finding includes a confidence rating, severity assessment, reproduction steps, and a proposed patch that can be applied directly in a Claude Code session. New features added from preview feedback include scheduled scans, directory-level targeting, Slack/Jira webhook integrations, and CSV/Markdown exports. Technology partners CrowdStrike, Palo Alto Networks, SentinelOne, TrendAI, and Wiz are embedding Opus 4.7 into their own platforms; access for Claude Team and Max customers is coming soon.

- **[Claude Code Advisor Tool (Beta) & Agent SDK Updates](https://releasebot.io/updates/anthropic/claude-code)** - Anthropic released the Advisor Tool in beta on the Claude Platform, letting a more powerful model (e.g., Opus 4.6/4.7) act as an advisor to a faster executor model (e.g., Sonnet). On SWE-bench Multilingual, the Sonnet+Advisor combo outperformed Sonnet alone across nine languages. Additional Claude Code updates this week include: Bedrock service tier selection via `ANTHROPIC_BEDROCK_SERVICE_TIER` (default/flex/priority), improved `/resume` PR search (paste a PR URL from GitHub, GitLab, or Bitbucket to find the originating session), MCP server auto-retry on transient errors (up to 3 times), expanded OpenTelemetry numeric attribute logging, and significant memory-leak fixes for image-heavy sessions and long-running tools.

- **[Managed Agents: Memory Now in Public Beta](https://releasebot.io/updates/anthropic/claude)** - Anthropic shipped cross-session Memory for Claude Managed Agents in public beta. Agents can now learn from each session using a filesystem-based memory layer that supports API control, audit logs, and portable memory stores—meaning enterprise teams can export, inspect, and share what agents have learned. This joins Dreaming (research preview), Outcomes, and Multiagent Orchestration already in public beta as part of the Managed Agents suite.

## OpenAI

- **[GPT-5.5-Cyber Rolls Out to Vetted Cybersecurity Defenders](https://openai.com/index/gpt-5-5-with-trusted-access-for-cyber/)** - OpenAI began rolling out GPT-5.5-Cyber in limited preview to critical infrastructure defenders through its Trusted Access for Cyber (TAC) program. The model is more permissive than standard GPT-5.5 for authorized dual-use workflows: red teaming, penetration testing, binary reverse engineering, and controlled exploitability validation. The broader TAC tier (available to more organizations) unlocks GPT-5.5 with fewer refusals for defensive tasks like vulnerability triage, malware analysis, and patch validation. Founding TAC participants include Bank of America, Cisco, Cloudflare, CrowdStrike, Goldman Sachs, JPMorgan Chase, Morgan Stanley, NVIDIA, Palo Alto Networks, and Zscaler. Starting June 1, 2026, individual users accessing the most capable TAC models will be required to enable phishing-resistant Advanced Account Security.

- **[ChatGPT Trusted Contact: Mental Health Safety Feature](https://openai.com/news/)** - OpenAI launched Trusted Contact in ChatGPT (May 7), a voluntary safety feature for personal consumer accounts. Users designate a trusted contact in settings; if automated systems and trained reviewers detect signals of serious self-harm risk in a conversation, ChatGPT may notify the contact and encourage them to check in. Not available for Business, Enterprise, or Edu workspaces. The feature is rolling out in supported regions for eligible personal accounts.

- **[ChatGPT Futures: Class of 2026 Initiative](https://openai.com/news/)** - OpenAI announced ChatGPT Futures: Class of 2026 (May 6), a program aimed at students and young builders. While details remain sparse, it aligns with OpenAI's stated goal of expanding access and building developer pipeline among younger users.

## Google AI

- **[Google I/O 2026 Preview: Gemini 4, "Remy" Agent, & Android Show (May 12)](https://io.google/2026/)** - Google I/O 2026 kicks off with The Android Show: I/O Edition on May 12 (10 AM PT), followed by the main developer conference May 19–20. Google has confirmed Gemini model updates and agentic coding are on the agenda. Expected announcements include Gemini 4 (rumored to natively support image and video generation in a unified model), "Remy"—an internal code name for a 24/7 AI agent designed to run digital errands and complete background tasks across third-party apps with minimal user intervention—and a Proactive Assistant feature that surfaces personalized suggestions from Gmail, Calendar, Drive, and on-screen context. A new premium subscription tier for advanced agentic features is widely anticipated.

- **[Gemini Embedding 2 Now Generally Available](https://releasebot.io/updates/google/gemini)** - Google announced general availability of Gemini Embedding 2 via the Gemini API and Vertex AI. The model is omnimodal, mapping text, images, video, audio, and PDFs into a unified semantic embedding space—eliminating lossy intermediate steps like OCR or transcription. It tops benchmarks across modalities and supports 100+ languages, giving developers a production-stable foundation for multimodal search and retrieval applications.

- **[Gemini 3 Deep Think Upgraded for Science & Engineering](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a major upgrade to Gemini 3 Deep Think, its specialized reasoning mode built for scientific and research challenges where problems lack clear guardrails and data is often messy. The updated Deep Think achieves gold-medal-level results on written sections of the 2025 International Physics Olympiad and Chemistry Olympiad, and scores 50.5% on CMT-Benchmark for advanced theoretical physics. Google AI Ultra subscribers can access it in the Gemini app now; API early access is available for researchers and enterprises.

## Developer Tools & Vibe Coding

- **[GitHub Copilot Moves to Usage-Based Billing on June 1](https://github.blog/news-insights/company-news/github-copilot-is-moving-to-usage-based-billing/)** - GitHub announced all Copilot plans will transition from premium-request-based billing to token-based GitHub AI Credits on June 1, 2026. Base plan pricing is unchanged (Pro $10/mo, Pro+ $39/mo, Business $19/user/mo, Enterprise $39/user/mo), and code completions/Next Edit Suggestions remain unlimited. All other Copilot features—Chat, cloud agent, Spaces, Spark, third-party coding agents—will consume AI Credits calculated on actual token consumption (input + output + cached). Heavy agentic users will likely see cost increases; light users may save. New sign-ups for individual Pro/Pro+ plans are currently paused while GitHub prepares the transition. A preview billing dashboard is rolling out in early May so users can estimate costs before June 1.

- **[Windsurf Wave 13: SWE-1.5 & Parallel Agents for All Tiers](https://neuronad.com/cursor-vs-windsurf/)** - Under Cognition ownership, Windsurf shipped Wave 13 bringing free SWE-1.5 model access and parallel agent sessions (via Git worktrees) to every subscription tier. SWE-1.5—a frontier-scale model served on Cerebras wafer-scale hardware—generates 950 tokens/second (6× faster than Claude Haiku 4.5, 13× faster than Sonnet 4.5), making it the fastest coding model available in any IDE. For vibe coding workflows that require rapid iteration and re-prompting, the speed advantage compounds meaningfully across a full work session.

- **[Google AI Vibe Coding Course Launches via Kaggle (June 2026)](https://releasebot.io/updates/google/gemini)** - Google and Kaggle opened registration for a June 2026 AI Agents Vibe Coding Course—a free course teaching developers how to use AI agents to build software without getting bogged down in syntax. The course expands Google's educational push alongside the Gemini for Developers Specialization on Coursera (updated April 2026) covering Gemini API, Google AI Studio, agentic workflows, and cloud deployment.
