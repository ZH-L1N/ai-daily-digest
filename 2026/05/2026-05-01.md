# AI Daily Digest - 2026-05-01

## Anthropic

- **[Project Glasswing & Claude Mythos Preview](https://www.anthropic.com/glasswing)** - Anthropic unveiled Project Glasswing, an industry-wide cybersecurity initiative joining AWS, Apple, Broadcom, Cisco, CrowdStrike, Google, JPMorganChase, the Linux Foundation, Microsoft, NVIDIA, and Palo Alto Networks. At its core is Claude Mythos Preview, an unreleased frontier model that has already autonomously found thousands of zero-day vulnerabilities in every major OS and web browser — including a 27-year-old OpenBSD flaw and a 16-year-old FFmpeg bug — and scores 93.9% on SWE-bench Verified (vs. 80.8% for Opus 4.6). Anthropic is committing $100M in model usage credits and $4M in direct donations to open-source security organizations; the model will not be made generally available but will be accessible to Glasswing partners at $25/$125 per million input/output tokens via Claude API, Bedrock, Vertex AI, and Microsoft Foundry.

- **[Anthropic & Amazon Expand Compute Partnership](https://www.anthropic.com/news/anthropic-amazon-compute)** - Anthropic signed a new agreement with Amazon to secure up to 5 gigawatts of capacity for training and deploying Claude over the next decade — a $100B+ commitment — spanning Graviton, Trainium2, Trainium3, and Trainium4 chips. The deal also brings the full Claude Platform directly inside AWS with unified billing, security, and governance, making Claude the only frontier AI model available on all three major clouds: AWS Bedrock, Google Cloud Vertex AI, and Microsoft Azure Foundry.

## OpenAI

- **[OpenAI Symphony: Open-Source Codex Orchestration](https://openai.com/index/open-source-codex-orchestration-symphony/)** - OpenAI released Symphony, an open-source agent orchestrator (Apache 2.0) that turns Linear issue trackers into a control plane for Codex agents — every open ticket automatically gets an autonomous coding agent assigned to it, running continuously until a pull request is ready for review. Teams inside OpenAI reported a 500% increase in landed PRs during the first three weeks, and the community has already extended it (v1.1.0) to support Claude Code, Gemini, and other models as alternative agent runtimes. Symphony has garnered over 15K GitHub stars and is positioned as a reference spec — not a maintained product — so teams can fork and adapt it.

- **[GPT-5.5 & Expanded AWS Partnership](https://openai.com/news/)** - GPT-5.5, OpenAI's most capable model to date, is available in ChatGPT for paid plans (Pro, Business, Enterprise, Edu) with faster agentic coding, stronger computer use, and better multi-step knowledge work. Alongside this, OpenAI and AWS expanded their partnership so GPT-5.5, Codex, and Amazon Bedrock Managed Agents powered by OpenAI are now in limited preview on AWS — giving enterprises OpenAI capabilities within the Bedrock security and governance stack. This follows the April 27 restructuring of the OpenAI-Microsoft partnership, under which Microsoft ended Azure revenue-share exclusivity, allowing OpenAI to now serve products across AWS and Google Cloud.

## Google AI

- **[Deep Research & Deep Research Max: New Gemini 3.1 Pro Agents](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google launched two new autonomous research agents built on Gemini 3.1 Pro: Deep Research (optimized for speed and interactive surfaces) and Deep Research Max (designed for exhaustive, background, asynchronous workflows). Both agents bring MCP support for connecting to private enterprise data, native chart and infographic visualizations, and dramatic benchmark gains — Deep Research Max scores 93.3% on DeepSearchQA (up from 66.1% in December) and 54.6% on Humanity's Last Exam. Gemini 3.1 Pro itself scored 77.1% on ARC-AGI-2, more than double the previous Gemini 3 Pro score; both agents are available now via the Interactions API, with consumer Gemini app access still pending.

- **[Google Cloud Next '26: Gemini Enterprise Agent Platform & 8th-Gen TPUs](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/next-2026/)** - At Cloud Next '26, Google announced the Gemini Enterprise Agent Platform — a one-stop shop for building, scaling, governing, and optimizing AI agents — alongside its eighth-generation TPUs (two specialized chips for training and inference in the agentic era) and the Virgo Network, a new megascale AI data center fabric. Google Cloud now has nearly 75% of customers using its AI products, with 330 customers processing over a trillion tokens each in the past 12 months; models now serve more than 16 billion tokens per minute via direct API.

## Developer Tools & Vibe Coding

- **[SpaceX Secures $60B Option to Acquire Cursor](https://techcrunch.com/2026/04/21/spacex-is-working-with-cursor-and-has-an-option-to-buy-the-startup-for-60-billion/)** - SpaceX preempted a $2B Cursor funding round (at a $50B valuation) by striking a deal giving it the right to acquire Cursor for $60B later in 2026, or pay $10B for collaborative AI development work using xAI's Colossus supercomputer. Cursor CEO Michael Truell said the company has been "bottlenecked by compute" and that Colossus will power further scaling of its Composer agentic coding model (Composer 2 now at frontier-level performance). The deal raises questions about model access — analysts note Anthropic previously restricted Windsurf's model access when OpenAI acquisition talks went public — and Microsoft reportedly examined a Cursor acquisition before declining to bid.

- **[Claude Code on Vertex AI & Agent Teams Momentum](https://www.anthropic.com/events)** - Anthropic is hosting a "Ship Code Faster with Claude Code on Vertex AI" webinar on May 6, reflecting strong enterprise traction for its terminal-native coding agent. Claude Code (80.9% SWE-bench Verified with Opus 4.5) holds 42% of enterprise coding workloads according to industry analysts, reached $1B annualized run rate in six months post-launch, and shipped Agent Teams for multi-agent coordination in February 2026. Codex from OpenAI crossed 4M active users less than two weeks after hitting 3M, reflecting the explosive growth in agentic coding adoption.

- **[Windsurf Arena Mode: Parallel Multi-Agent Sessions](https://www.nxcode.io/resources/news/cursor-vs-windsurf-vs-claude-code-2026)** - Windsurf launched Arena Mode, enabling developers to run multiple Cascade agents simultaneously using Git worktrees with side-by-side panes — a capability previously unique to Claude Code's Agent Teams. The feature is free for the first week for paid users, and at $15/month Windsurf remains 25% cheaper than Cursor's $20/month Pro plan. GitHub Copilot's 2026 updates added a Coding Agent that can autonomously work on GitHub issues, create branches, write code, and open PRs, plus model selection across GPT-4o, Claude, and Gemini.
