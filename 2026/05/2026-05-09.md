# AI Daily Digest - 2026-05-09

## Anthropic

- **[Claude Opus 4.7 Launches with Stronger Coding & Vision](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic released Claude Opus 4.7, featuring substantially improved vision at higher image resolution, better "taste" for visual design work (interfaces, slides, docs), and state-of-the-art coding performance—a 13% lift on their 93-task benchmark vs. Opus 4.6. It is the first Claude model equipped with new cyber safeguards that automatically detect and block high-risk cybersecurity requests. Available across all Claude products, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry at unchanged pricing ($5/M input, $25/M output).

- **[Anthropic + SpaceX Deal Doubles Claude Code Rate Limits](https://9to5google.com/2026/05/06/claude-code-is-getting-higher-usage-limits-doubled-for-most-users/)** - Anthropic signed a deal with SpaceX to access all compute capacity at the Colossus 1 data center—over 300 megawatts and 220,000+ NVIDIA GPUs. As a direct result, Claude Code's five-hour rate limits are now doubled for Pro, Max, Team, and Enterprise (seat-based) plans, and peak-hour reductions for Pro and Max have been removed. Claude API limits also saw dramatic increases (e.g., Tier 1 input tokens per minute up ~1500%).

- **[Full Microsoft 365 Integration & Wall Street Push](https://fortune.com/2026/05/05/anthropic-wall-street-financial-services-agents-jamie-dimon/)** - At an invite-only financial services briefing in New York (May 5), Anthropic unveiled full Microsoft 365 integration—Claude now operates as a single agent across Excel, PowerPoint, Word, and Outlook simultaneously. Excel/PowerPoint/Word add-ins went GA; Outlook launched in beta. Moody's will embed its full platform (600M+ companies) into Claude as a native app, and Anthropic confirmed a $1.5B joint venture with Blackstone, Hellman & Friedman, and Goldman Sachs for forward-deployed AI enterprise services.

- **[Claude Will Remain Ad-Free](https://www.anthropic.com/news)** - Anthropic published a stance piece confirming Claude will stay ad-free, arguing advertising incentives are fundamentally incompatible with a genuinely helpful AI assistant. The announcement is a direct contrast to OpenAI's expanding ChatGPT ads platform and Anthropic even ran a Super Bowl ad making this point.

- **[Claude Code Bug Fixes & Feature Updates](https://releasebot.io/updates/anthropic/claude-code)** - Claude Code shipped several improvements this week: added `--plugin-url` flag to load plugins from a URL per session, fixed VS Code extension activation on Windows (hardcoded build path bug), fixed Mantle endpoint authentication (missing `x-api-key` header), added Bedrock service tier selection via `ANTHROPIC_BEDROCK_SERVICE_TIER` env var, and improved `/resume` PR search to match sessions via pasted PR URLs from GitHub, GitLab, and Bitbucket.

## OpenAI

- **[GPT-5.5 Instant Becomes ChatGPT's New Default Model](https://openai.com/index/gpt-5-5-instant/)** - OpenAI replaced GPT-5.3 Instant with GPT-5.5 Instant as the default ChatGPT model for all users. The new model produces 52.5% fewer hallucinated claims on high-stakes prompts (medicine, law, finance), uses ~30% fewer words for more concise answers, and improves personalization by pulling context from past chats, files, and connected Gmail. Enhanced personalization is rolling out to Plus and Pro users on web first, with Free/Go/Business/Enterprise to follow.

- **[Three New Realtime Voice API Models for Developers](https://openai.com/index/advancing-voice-intelligence-with-new-models-in-the-api/)** - OpenAI launched three new audio models on May 7: GPT-Realtime-2 (first voice model with GPT-5-class reasoning, 128K context window, adjustable reasoning effort), GPT-Realtime-Translate (live speech translation from 70+ input languages into 13 output languages), and GPT-Realtime-Whisper (streaming speech-to-text transcription). GPT-Realtime-2 scored 15.2% higher on Big Bench Audio vs. its predecessor; early adopters include Zillow (26-point call success rate lift) and Deutsche Telekom. Priced at $32/1M audio input tokens; translate at $0.034/min; whisper at $0.017/min.

- **[ChatGPT Ads Expand with Self-Serve Manager & CPC Bidding](https://openai.com/index/testing-ads-in-chatgpt/)** - OpenAI expanded its ads platform with a beta self-serve Ads Manager and new cost-per-click (CPC) bidding (alongside existing CPM). The program is expanding globally to the UK, Mexico, Brazil, Japan, and South Korea. Ads appear only for free and Go-tier users, are clearly labeled, and OpenAI insists ads do not influence model responses. Annualized ad revenue has reportedly already crossed $100M; OpenAI targets $2.5B in ad revenue for 2026 and $100B by 2030.

## Google AI

- **[Gemini macOS App Preparing Computer-Use Agent Capabilities](https://9to5google.com/2026/05/05/gemini-agent-macos-organize-files/)** - APK Insight reveals Google is developing agentic computer-use features for the Gemini macOS app to directly rival Claude Cowork. Spotted prompt templates indicate Gemini will scan local folders, organize files, batch-rename documents, and draft follow-up emails from Google Meet notes—using Screen Access and Accessibility APIs for full control. The native Gemini macOS app (launched April 15, free for macOS 15+ on Apple Silicon) is the foundation for this upcoming expansion, expected to be formally announced at Google I/O 2026 (May 19-20).

- **[AlphaEvolve One-Year Impact: $1.3B/yr Savings, Quantum Breakthroughs](https://deepmind.google/blog/alphaevolve-impact/)** - Google DeepMind published a sweeping one-year impact report for AlphaEvolve, its Gemini-powered algorithm design agent. Key results: 5% improvement in natural disaster risk prediction accuracy (across 20 categories), 10x lower error rates in quantum circuit optimization on the Willow quantum processor, and graduating from pilot to a "core component" of Google's infrastructure for designing next-generation TPUs. The team estimates AlphaEvolve's optimizations save Google approximately $1.3B annually.

- **[Deep Research Max (Gemini 3.1 Pro) Now Available for Developers](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google launched two tiers of autonomous research agents via the Interactions API: Deep Research (optimized for speed and interactive UX with reduced latency) and Deep Research Max (built for maximum comprehensiveness using extended test-time compute, ideal for overnight batch workflows). Both run on Gemini 3.1 Pro, support MCP connections to private/enterprise data sources, and can generate professional visualizations. Deep Research Max scored 85.9 on BrowseComp—more than 25 points above Gemini 3 Pro.

## Developer Tools & Vibe Coding

- **[SpaceX Places $60B Buyout Option on Cursor, Injects $10B](https://techcrunch.com/2026/04/22/how-spacex-preempted-a-2b-fundraise-with-a-60b-buyout-offer/)** - SpaceX (now merged with xAI) pre-empted Cursor's planned $2B fundraise by striking a deal: $10B in upfront AI collaboration funding and an exclusive option to acquire Cursor for $60B before year-end. Cursor has reached $2B in annualized revenue and is used by 64%+ of Fortune 500 companies. The deal pairs Cursor's 1M+ developer distribution with SpaceX's Colossus supercomputer; any full acquisition is deferred until after SpaceX's planned summer IPO to avoid updating confidential financial filings.

- **[Windsurf 2.0 Ships Under Cognition with Parallel Multi-Agent Sessions](https://www.shareuhack.com/en/posts/cursor-vs-claude-code-vs-windsurf-2026)** - Following the complex three-way split (Google acqui-hired founders for $2.4B; Cognition acquired remaining IP/team for ~$250M), Windsurf 2.0 launched in April 2026 with an Agent Command Center and Devin integration. Wave 13 added Parallel Multi-Agent Sessions (via Git worktrees) and Arena Mode for blind model quality testing. Windsurf Pro pricing rose from $15 to $20/month, now matching Cursor.

- **[Perplexity Personal Computer Agent Now on Mac for All Users](https://coaio.com/news/2026/05/breaking-tech-news-on-may-8-2026-ai-innovations-space-races-and-2pcc/)** - Perplexity's Personal Computer AI agent is now available for all Mac users. The agent can access local files, native Mac apps, the web, and 400+ connectors, entering the increasingly crowded desktop AI agent space alongside Claude Cowork, the ChatGPT Mac app, and the upcoming Gemini computer-use features.

- **[Airbnb: AI Now Writes 60% of All New Code](https://coaio.com/news/2026/05/breaking-tech-news-on-may-8-2026-ai-innovations-space-races-and-2pcc/)** - Airbnb disclosed that AI tools now generate 60% of all new code written at the company. This is a notable enterprise milestone and joins similar announcements from Shopify and Mercado Libre (which is targeting 90% autonomous coding by Q3 2026 per Anthropic's "Code w/ Claude" event), illustrating how AI coding assistants are moving from developer tools to core engineering infrastructure.
