# AI Daily Digest - 2026-05-02

## Anthropic

- **[Claude Security Now in Public Beta for Enterprise Customers](https://www.business-standard.com/technology/tech-news/anthropic-announces-claude-security-beta-for-enterprise-customers-126050100019_1.html)** - Anthropic officially launched Claude Security (previously Claude Code Security) in public beta on May 1 for all Claude Enterprise customers. Powered by Claude Opus 4.7, the product lets security teams scan codebases for vulnerabilities and auto-generate targeted patches. Major tech and consulting partners — including CrowdStrike, Microsoft Security, Palo Alto Networks, SentinelOne, Wiz, Accenture, BCG, Deloitte, Infosys, and PwC — are now embedding or deploying the tool across organizations.

- **[Claude Opus 4.7 Generally Available](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic shipped Claude Opus 4.7 on April 16, its strongest generally available model to date, with notable gains in advanced software engineering and multi-step agentic work. New highlights include 3x image resolution (up to 2,576 px on the long edge), a new `xhigh` effort level in Claude Code (now the default), a `/ultrareview` command that deploys a fleet of remote agents to hunt verified bugs in PRs, task budgets in public beta, and auto mode extended to Max plan users. Pricing remains $5/$25 per million input/output tokens.

- **[Anthropic Investigates Unauthorized Access to Mythos Model](https://www.engadget.com/ai/anthropic-is-investigating-unauthorized-access-of-its-mythos-cybersecurity-tool-091017168.html)** - A small group gained access to the restricted Claude Mythos Preview on the same day it was announced, reportedly by exploiting a third-party contractor portal and guessing the model's API endpoint based on Anthropic's past naming patterns. The group has been using the model continuously but not maliciously. Anthropic confirmed it is "investigating a report claiming unauthorized access to Claude Mythos Preview through one of our third-party vendor environments" and says there is no evidence of broader system compromise.

- **[Claude Code Broad Update: Project Purge, Gateway Model Picker, Bedrock Tiers & More](https://releasebot.io/updates/anthropic/claude-code)** - The latest Claude Code release adds a `claude project purge` command to wipe all project state (transcripts, tasks, file history), a gateway-aware `/model` picker that lists models from a custom `ANTHROPIC_BASE_URL`, `ANTHROPIC_BEDROCK_SERVICE_TIER` support for flex/priority tier selection, improved OAuth login for WSL2/SSH/container environments, and a `claude ultrareview [target]` CI subcommand for non-interactive pipeline reviews. Windows users also get PowerShell as a shell fallback when Git Bash is absent.

## OpenAI

- **[GPT-5.5-Cyber Restricted Rollout Announced for Critical Defenders](https://www.businesstoday.in/technology/story/openai-to-roll-out-gpt-55-cyber-with-restricted-access-sam-altman-528193-2026-04-30)** - CEO Sam Altman announced on April 30 that OpenAI will begin shipping GPT-5.5-Cyber — a security-focused variant of GPT-5.5 — to a vetted group of "critical cyber defenders" within days. The model supports penetration testing, vulnerability identification and exploitation, and malware reverse engineering. The UK's AI Security Institute rated it "one of the strongest models we have tested on our cyber tasks," noting it is only the second system to complete one of their multi-step attack simulations end-to-end — though AISI also discovered a universal jailbreak bypassing its safeguards during red-teaming.

- **[GPT-5.5 Now Available in the API + Advanced Account Security for ChatGPT](https://openai.com/index/introducing-gpt-5-5/)** - GPT-5.5 and GPT-5.5 Pro became available via the API on April 24 for Plus, Pro, Business, Enterprise, and Edu plans, after an initial ChatGPT-only rollout. The model excels at agentic coding, computer use, and knowledge work. Separately, OpenAI launched Advanced Account Security for ChatGPT — an opt-in setting adding phishing-resistant passkey sign-in, shorter sessions, login alerts, and secure account recovery; it extends to Codex users and will be required for Trusted Access for Cyber members starting June 1.

- **[OpenAI Expands to Amazon Bedrock, Breaking Microsoft Exclusivity](https://www.marketingprofs.com/opinions/2026/54640/ai-update-may-1-2026-ai-news-and-views-from-the-past-week)** - OpenAI and Microsoft renegotiated their partnership to end exclusivity, allowing OpenAI models to be distributed through Amazon Web Services and other cloud providers. Codex is now available on Amazon Bedrock, giving enterprises a multi-cloud path to OpenAI's flagship coding agent. OpenAI simultaneously reported Codex has crossed 4 million active users and the company surpassed $25 billion in annualized revenue.

## Google AI

- **[Deep Research Max Launched with Gemini 3.1 Pro, MCP Support & Native Visualizations](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google DeepMind introduced two new autonomous research agents via the Interactions API: Deep Research (optimized for low-latency interactive surfaces) and Deep Research Max (optimized for maximum comprehensiveness using extended test-time compute). Both are built on Gemini 3.1 Pro and connect to internal data sources via the Model Context Protocol, enabling exhaustive research pipelines that blend public web data with proprietary data streams. On the BrowseComp benchmark, Gemini 3.1 Pro scored 85.9 — more than 25 points higher than Gemini 3 Pro.

- **[Gemini Rolling Out to Millions of Vehicles via Google Built-In](https://techcrunch.com/2026/04/30/googles-gemini-ai-assistant-is-hitting-the-road-in-millions-of-vehicles/)** - Google announced it is rolling out Gemini to cars with Google built-in, starting in the US with English-language support. General Motors confirmed Gemini is coming to approximately 4 million vehicles from model year 2022 and newer across Cadillac, Chevrolet, Buick, and GMC brands via OTA software updates. Gemini in-car can handle navigation, climate control, music recommendations, and hands-free message summaries, with future integration planned for Gmail, Google Calendar, and Google Home.

- **[Gemini on Google TV Adds Image Editing & Video Creation](https://www.business-standard.com/technology/tech-news/google-tv-gemini-edit-images-create-videos-nano-banana-veo-126043000515_1.html)** - Google TV received a Gemini-powered update enabling image editing and short video creation directly on the TV, powered by the Nano Banana image model and Veo for video generation. The update extends Gemini's reach into the living room, positioning Google TV as a creative surface beyond streaming.

## Developer Tools & Vibe Coding

- **[SpaceX Strikes $60B Acquisition Option for AI Coding Startup Cursor](https://techcrunch.com/2026/04/21/spacex-is-working-with-cursor-and-has-an-option-to-buy-the-startup-for-60-billion/)** - SpaceX (merged with xAI in February) announced a deal with Cursor: a $10 billion collaboration to build "the world's best coding and knowledge work AI," with an option to acquire Cursor outright for $60 billion later this year after SpaceX's IPO. Cursor will gain access to xAI's Colossus supercomputer to accelerate model training — critical because Cursor currently relies entirely on Anthropic and OpenAI models. The deal preempted a $2B fundraise at a $50B valuation; Microsoft had also reportedly explored a bid before passing.

- **[Claude Code Gets /ultrareview, Auto Mode for Max Users, and CI Subcommand](https://venturebeat.com/technology/anthropic-releases-claude-opus-4-7-narrowly-retaking-lead-for-most-powerful-generally-available-llm)** - Alongside Opus 4.7, Claude Code shipped `/ultrareview`, which launches a fleet of remote reviewer agents in a cloud sandbox to find and verify bugs in a branch or PR — each finding is independently reproduced before being reported. Auto mode (no permission prompts for tool calls) was expanded from Team/Enterprise to Max plan subscribers. A new `claude ultrareview [target]` CI subcommand enables non-interactive ultrareviews from CI/CD pipelines.

- **[Windsurf Adds Parallel Multi-Agent "Arena Mode"](https://www.nxcode.io/resources/news/cursor-vs-windsurf-vs-claude-code-2026)** - Windsurf's latest update introduced Arena Mode, enabling multiple Cascade agents to run simultaneously using Git worktrees with side-by-side panes — a capability previously exclusive to Claude Code's Agent Teams. Arena Mode is free for the first week for paid users and significantly narrows the feature gap with Cursor's agent mode. Windsurf remains the lowest-priced major AI IDE at $15/month Pro, vs. Cursor's $20/month.
