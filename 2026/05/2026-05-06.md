## Anthropic

- **[Claude Code: Bedrock Tier Selection, /resume PR Search & OpenTelemetry Expansion](https://releasebot.io/updates/anthropic/claude-code)** - The latest Claude Code release adds an `ANTHROPIC_BEDROCK_SERVICE_TIER` environment variable allowing developers to select between default, flex, or priority Bedrock service tiers via the `X-Amzn-Bedrock-Service-Tier` header. ## OpenAI

- **[GPT-5.5 Instant Is Now ChatGPT's Default Model](https://openai.com/index/gpt-5-5-instant/)** - OpenAI rolled out GPT-5.5 Instant on May 5 as the new default model for all ChatGPT users, replacing GPT-5.3 Instant. Internal evaluations show 52.5% fewer hallucinated claims on high-stakes prompts (medicine, law, finance) and 37.3% fewer inaccurate claims on user-flagged conversations. Responses are also tighter — using ~30% fewer words and ~29% fewer lines — while a new memory sources feature lets Plus and Pro users on the web pull context from past chats, uploaded files, and Gmail for more personalized answers. Developers can access the model via API as `chat-latest`; GPT-5.3 Instant remains available to paid users for three months.

- **[OpenAI's Greg Brockman Reveals $50 Billion Compute Spend for 2026](https://www.bloomberg.com/news/articles/2026-05-05/openai-to-spend-50-billion-on-computing-in-2026-brockman-says)** - OpenAI President Greg Brockman testified on May 5 during the company's ongoing court battle with Elon Musk that OpenAI expects to spend $50 billion on computing power in 2026 alone — up from roughly $30 million in 2017. The disclosure underscores how rapidly scaling AI infrastructure costs have become central to competitive strategy, and provides rare public insight into OpenAI's financial trajectory as the company pushes advanced model development and serves over 900 million weekly active users.

- **[Advanced Account Security for ChatGPT and Codex](https://openai.com/index/advanced-account-security/)** - OpenAI's opt-in Advanced Account Security (announced May 4) adds phishing-resistant sign-in, disables email/SMS recovery in favor of hardware keys and passkeys, shortens session durations, and sends login alerts. Protection extends to Codex users as well. Members of Trusted Access for Cyber must enroll by June 1, 2026. The feature reflects a broader trend of AI platforms hardening account security as AI accounts increasingly sit at the center of sensitive personal and professional workflows.

## Google AI

- **[Google DeepMind UK Workers Vote to Unionize Over Pentagon Deal](https://fortune.com/2026/05/05/google-deepmind-workers-in-the-u-k-vote-to-unionize-over-military-ai-contracts-internal-backlash-pentagon-deal-israeli-defense-forces/)** - Google's UK-based DeepMind workers launched a bid on May 5 to form the world's first union at a frontier AI lab, directly in response to Google's recently signed contract allowing the U.S. Department of Defense to use Gemini models inside classified military networks "for any lawful purpose." The effort — organized through the Communications Workers Union — includes planned in-person protests and research strikes. The development echoes the 2018 Project Maven employee revolt, though analysts note Google has since made internal organizing harder by decommissioning internal mailing lists and the company's intranet social network.

- **[Google I/O 2026 Countdown: Gemini 4 Preview Imminent](https://android.gadgethacks.com/news/inside-the-google-io-2026-countdown-5-gemini-games-you-can-remix/)** - Google I/O 2026 kicks off May 19–20 at Shoreline Amphitheatre, and Google is drumming up developer excitement with five Gemini-powered interactive games in AI Studio that let developers remix and publish their own versions. The conference is widely expected to preview Gemini 4 — reportedly scoring 84.6% on ARC-AGI2 with a 2M+ token context window — alongside Aluminum OS, Android XR smart glasses (with Warby Parker), and Ironwood TPUs at 42.5 exaflops. Developers can already explore the pre-I/O games (including a real-time AI caddy mini-golf game and a procedural logic puzzle) at Google AI Studio.

- **[Gemini 3 Deep Think Upgraded for Science & Engineering](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a major upgrade to Gemini 3 Deep Think (its specialized extended reasoning mode), now achieving gold medal-level results on the written sections of the 2025 International Physics and Chemistry Olympiads and scoring 50.5% on CMT-Benchmark for advanced theoretical physics. The updated Deep Think is available now in the Gemini app for Google AI Ultra subscribers, with an early API access program open to researchers, engineers, and enterprises. Early testers include mathematicians at Rutgers and materials scientists at Duke University.

## Developer Tools & Vibe Coding

- **[Cursor 3 Lands at #1 in AI Dev Tool Rankings](https://blog.logrocket.com/ai-dev-tool-rankings)** - Cursor jumped from #3 to #1 in LogRocket's May 2026 AI dev tool power rankings, following the April 2026 launch of Cursor 3 — a ground-up agent-first rebuild featuring Composer 2 (a proprietary frontier coding model at 200+ tok/s), a dedicated Agents Window, cloud-to-local agent handoff, and a new Design Mode for visual UI iteration. Claude Code moved up to #3 (behind Windsurf at #2) as Opus 4.7 and the new `/ultrareview` command strengthened its CLI-first workflow. Among surveyed developers, Claude Code holds a 46% "most loved" rating vs. 19% for Cursor and 9% for Copilot.

- **[OpenAI Codex on Amazon Bedrock: Cloud Coding Agent in AWS Ecosystem](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-whats-next-with-aws-2026-amazon-quick-openai-partnership-and-more-may-4-2026/)** - OpenAI Codex is now accessible on Amazon Bedrock in limited preview, letting developers run the `codex-1` reasoning agent via their existing AWS credentials through the Codex CLI, a macOS desktop app, and a VS Code extension. Usage counts toward AWS cloud commitments and is processed through Bedrock with unified security and governance controls. The integration opens Codex's fully autonomous coding capabilities — write files, run servers, push to GitHub — to the vast AWS developer ecosystem without requiring separate OpenAI account management.

- **[Vibe Coding Landscape: 95% of Devs Use AI Weekly, Cloud Agents Define Era 3](https://qubittool.com/blog/ai-coding-tools-2026-comparison)** - According to 2026 developer survey data, 95% of developers use AI tools at least weekly, with 75% using AI for more than half of all coding work — and the average experienced developer now uses 2.3 AI coding tools simultaneously. The industry has entered what analysts call "Era 3" — Cloud Agents — where tools like Cursor Background Agents, Copilot's Coding Agent, and Claude Code's GitHub Actions integration can continue working asynchronously after a developer closes their laptop, submitting pull requests for review. Context engineering (crafting rule files, project docs, and examples) is increasingly called the essential AI coding skill of 2026, with well-crafted context lifting agent task success rates from 30% to 90%.
