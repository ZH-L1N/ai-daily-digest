# AI Daily Digest - 2026-05-04

## Anthropic

- **[Claude Code: Opus 4.7 Now Default, Adds xhigh Effort, /ultrareview, Routines, and Web Redesign](https://releasebot.io/updates/anthropic/claude-code)** - Claude Code shipped a sweeping update making Claude Opus 4.7 the new default model for Max and Team Premium subscribers, with a new `xhigh` effort level (between high and max) recommended for most coding work, accessible via an interactive `/effort` slider. The release also adds `/ultrareview` for parallel multi-agent cloud code review, Routines on the web version to fire templated agents on a schedule or GitHub/API event, a `/usage` command to diagnose what's consuming limits, and a full web UI redesign with a sessions sidebar and drag-and-drop layout. The CLI also migrates to native binaries, and a session-recap feature now shows a summary of what Claude did while a terminal was unfocused.

- **[Claude API Retires 1M Context Beta for Sonnet 4.5 and Sonnet 4](https://platform.claude.com/docs/en/release-notes/overview)** - Anthropic retired the `context-1m-2025-08-07` beta header for Claude Sonnet 4.5 and Claude Sonnet 4; requests exceeding the standard 200k-token window will now return an error for those models. Developers needing a 1M context window should migrate to Claude Sonnet 4.6 or Opus 4.6, where it is generally available at standard pricing with no beta header required.

- **[Mythos Unauthorized-Access Investigation Continues; White House Blocks Glasswing Expansion](https://www.mindstudio.ai/blog/claude-mythos-27-year-openbsd-vulnerability-white-house)** - Anthropic's investigation into unauthorized Discord-group access to Claude Mythos Preview through a third-party vendor remains ongoing; the company says no evidence of impact beyond that vendor environment has been found. Separately, the White House blocked Anthropic's plan to expand Project Glasswing membership from 50 to 120 organizations, citing concerns over compute prioritization and national security control of the ultra-capable vulnerability-discovery model.

## OpenAI

- **[GPT-5.5-Cyber Begins Restricted Rollout to Critical Cyber Defenders](https://techcrunch.com/2026/04/30/after-dissing-anthropic-for-limiting-mythos-openai-restricts-access-to-cyber-too/)** - OpenAI's cybersecurity-focused GPT-5.5-Cyber model is now actively rolling out to vetted government agencies, critical-infrastructure operators, and security researchers through the Trusted Access for Cyber (TAC) program at chatgpt.com/cyber. The UK AI Security Institute confirmed GPT-5.5-Cyber is "one of the strongest models we have tested on our cyber tasks" and is only the second system ever to complete one of their multi-step attack simulations end-to-end. The restricted release mirrors Anthropic's Project Glasswing approach — a strategic reversal that drew irony after CEO Sam Altman had criticized Mythos's gated rollout just weeks earlier.

- **[ChatGPT Workspace Agents Exit Free Preview — Credit Billing Starts May 6](https://venturebeat.com/orchestration/openai-unveils-workspace-agents-a-successor-to-custom-gpts-for-enterprises-that-can-plug-directly-into-slack-salesforce-and-more)** - The two-week free period for ChatGPT Workspace Agents (OpenAI's successor to custom GPTs, powered by Codex) ends on May 6, 2026, when credit-based consumption pricing begins. Teams on Business, Enterprise, Edu, and Teachers plans have until tomorrow to benchmark usage patterns before billing kicks in. The agents connect to Slack, Google Drive, Salesforce, Atlassian Rovo, and 90+ tools, and can run cloud-side tasks without a human present — positioning them as the enterprise counterpart to Anthropic's Claude Code for developer-side agentic work.

## Google AI

- **[Google Signs Classified Pentagon AI Deal; ~1,000 Employees Sign Protest Letter](https://fortune.com/2026/05/04/google-employee-backlash-pentagon-ai-contract-power-waned-since-project-maven/)** - Google has finalized an amendment to its existing Pentagon contract granting the Department of Defense access to Gemini models for "any lawful governmental purpose" on classified networks — the most permissive AI deal the DoD has signed to date, according to legal experts. The news has sparked a growing employee revolt: the open letter opposing the deal, initially signed by ~600 staff, has now surpassed 1,000 signatures, including senior DeepMind researchers who said publicly they spent months trying to prevent the agreement. The backlash echoes Google's 2018 Project Maven protest, but Google leadership has not reversed course, arguing that engagement offers more oversight than abstention, and noting that every other major AI lab — OpenAI, xAI, Microsoft, Nvidia, Amazon — has signed similar classified-access terms.

- **[Gemini API: New Flash TTS, Robotics Model, and Deprecation Warnings](https://ai.google.dev/gemini-api/docs/changelog)** - Google updated the Gemini API with Gemini 3.1 Flash TTS Preview — a cost-efficient, expressive, steerable text-to-speech model — alongside an updated robotics model (gemini-robotics-er-1.6-preview) featuring improved instrument reading and spatial/physical reasoning. Developers using the older er-1.5-preview robotics model should note its shutdown on April 30, 2026 is now past, while several Gemini 2.5-era models are now queued for shutdown on June 1, 2026.

## Developer Tools & Vibe Coding

- **[Mistral Le Chat Gets 128B Flagship Model, Async Cloud Coding Sessions, and Agentic Work Mode](https://llm-stats.com/ai-news)** - Mistral AI released a major Le Chat update introducing a new 128B flagship model, asynchronous cloud-based coding sessions that can run independently in the background, and an agentic "Work" mode for multi-step task execution — directly competing with OpenAI Codex and Claude Code for the cloud-agent coding market. The 128B model is designed to deliver frontier-class coding and reasoning performance, while the async session model lets developers hand off long-running tasks and return to results.

- **[Chinese Open-Weight Coding Models Challenge Western Frontier at a Fraction of the Cost](https://nathanbenaich.substack.com/p/state-of-ai-may-2026)** - Four Chinese labs shipped competitive open-weight coding models within a 12-day window: Zhipu AI's GLM-5.1, MiniMax M2.7, Moonshot's Kimi K2.6, and DeepSeek V4 all hit roughly the same capability ceiling on agentic engineering benchmarks as the Western frontier — while costing less than a third of Claude Opus 4.7 per token. Kimi K2.6 has drawn particular attention after beating Claude, GPT-5.5, and Gemini in a head-to-head programming challenge. The releases are significant for vibe-coding workflows where inference cost determines iteration speed and accessibility for individual developers.
