# AI Daily Digest — 2026-09-12 🤖

## Anthropic
• Claude Code ships broad release with plugin evals and output-style switching — new `claude plugin eval` command runs a plugin's eval suite against Claude Code and returns scored, reproducible JSON/HTML results; output-style switching lets users change response styles mid-session; also adds stronger telemetry and workflow controls and fixes sustained CPU spikes, broken MCP tool calls after idle, and directory-symlink permission issues across CLI, VS Code, web, and Slack surfaces; first seen Sept 11 — makes Claude Code plugin development formally testable and moves the platform closer to professional IDE-grade reliability — https://docs.anthropic.com/en/release-notes/claude-code

• Claude Enterprise gets Smart Reports in beta — analyzes how a team uses Claude and reports on work completed, session costs, friction points, and repeated patterns worth packaging as shared skills; also ships auto permission policies for Managed Agents (server evaluates each agent or MCP tool call, then runs, denies, or pauses for approval) — gives enterprise admins an ROI dashboard and fine-grained governance over agentic workflows — https://docs.anthropic.com/en/release-notes/claude-apps

## OpenAI
• Agents API launches in public beta — puts the Codex harness behind a single managed API: handles session orchestration, automatic context compaction, tool search (loads definitions on demand to reduce token use), parallel tool calling, and multi-agent subagent delegation; runs in OpenAI-hosted sandboxes or nine partner environments (Cloudflare, Daytona, DigitalOcean, E2B, Modal, Oracle, Runloop, Vercel, Blaxel); no fees beyond standard token and tool usage; early adopters report a 4× latency reduction and 60% cost drop per case — eliminates the boilerplate of building production-grade long-running agents and brings Codex infrastructure to any developer — https://openai.com/index/introducing-the-agents-api/

• GPT-Live-1 generally available in the API alongside ChatGPT for Financial Services — GPT-Live-1 is a full-duplex speech-to-speech model that listens while it talks, letting developers build voice agents with their own backend model and harness; ChatGPT for Financial Services launches simultaneously as a compliance-ready enterprise tier tailored to banks and financial firms — extends Astra-era voice capability to third-party builders while pushing into a new high-value regulated vertical — https://openai.com/products/release-notes/

## Google AI
• Gemini Robotics ER 2 enters public preview with multi-robot coordination and real-time streaming — two new endpoints: gemini-robotics-er-2-preview (advanced spatial reasoning, agentic code execution, multi-step tool orchestration, video moment finding, progress classification, multi-robot coordination) and gemini-robotics-er-2-streaming-preview (real-time low-latency robot agents with bidirectional audio/video via the Live API); both accept text, image, video, and audio inputs and support function calling with blocking behavior for physical robot actions — gives robotics developers a hosted cloud API for embodied reasoning, reducing the engineering lift to prototype and coordinate multi-robot systems — https://ai.google.dev/gemini-api/docs/changelog

• Gemini Windows app launches globally — native desktop app for Windows 10 and 11 surfaces Gemini via Alt+Space from any window; connects to Gmail and Drive for contextual assistance; supports image generation and deep-research mode; available now at gemini.google/desktop — puts Google's AI assistant into the OS layer, competing directly with Microsoft Copilot which has had native Windows integration for over two years — https://gemini.google/desktop

## Industry, Deals & Policy
