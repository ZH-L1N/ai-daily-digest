## Developer Tools & Vibe Coding
• Trojanized Claude Code extension (v2.1.313) distributed via Cursor's VS Code marketplace for 11 hours on Oct 29 exposed up to 5,000 developers to a persistent SSH backdoor — attackers injected a 66-line loader that planted an attacker-controlled SSH key labeled svc-telemetry, installed OS-level persistence, and beaconed host reconnaissance data; Anthropic confirmed its own systems were not compromised; Cursor rebuilt the marketplace and rotated all keys — AI coding teams that used Cursor on Oct 29 must check authorized_keys for the svc-telemetry key and rotate credentials — https://cursor.com/blog/claude-code-extension-security-notice
