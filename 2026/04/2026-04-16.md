# AI Daily Digest - 2026-04-16

## Anthropic
- **[Claude Opus 4.7 Released](https://cryptobriefing.com/anthropic-releases-claude-opus-47-impacting-ai-model-market-standings/)** - Anthropic confirmed the release of Claude Opus 4.7 on April 16, 2026, with notable improvements in advanced software engineering, vision capabilities, and long-running agentic task performance. The model catches logical faults during planning, handles complex async workflows including CI/CD pipelines, and is designed for hands-off execution of hard coding tasks. It also adds new effort controls, task budgets, and Claude Code review tools.

- **[Claude Code Adds /tui Fullscreen & Mobile Push Notifications](https://releasebot.io/updates/anthropic/claude-code)** - A Claude Code update first seen April 16 introduces `/tui` fullscreen rendering for flicker-free terminal output, a push notification tool so Claude can alert you on mobile when Remote Control completes, a new `/focus` command to toggle focus view separately from verbose transcript, and an `autoScrollEnabled` config to disable auto-scroll in fullscreen mode. This continues a rapid cadence of Claude Code improvements throughout April.

## OpenAI
- **[GPT-5.4-Cyber Launched for Defensive Security](https://www.reuters.com/technology/openai-unveils-gpt-54-cyber-week-after-rivals-announcement-ai-model-2026-04-14/)** - On April 14, OpenAI unveiled GPT-5.4-Cyber, a variant of its flagship model fine-tuned specifically for defensive cybersecurity work, following Anthropic's Claude Mythos announcement. The model is initially available to vetted security vendors, organizations, and researchers via the expanded Trusted Access for Cyber program, which is being broadened to thousands of individual defenders and hundreds of critical-software protection teams.

- **[OpenAI Agents SDK Gets Sandboxing & Long-Horizon Harness](https://www.openlinksw.com/data/html/openai-agents-sdk-next-evolution-infographic.html)** - OpenAI updated the Agents SDK with a model-native long-horizon harness and native sandbox execution for safer file, tool, and code workflows. The harness gives developers configurable memory, standardized integrations, portable workspace support, and built-in snapshotting for durable multi-step agent runs. Python support is live now; TypeScript and subagents/code-mode support are coming next.

## Google AI
- **[Gemini Robotics-ER 1.6 Available via API](https://deepmind.google/blog/gemini-robotics-er-1-6/)** - Google DeepMind released Gemini Robotics-ER 1.6 on April 14, a significant upgrade to its "Embodied Reasoning" model for physical AI agents. The model features enhanced spatial reasoning (pointing, counting, object detection), multi-view success detection, and a new "agentic vision" capability that combines visual reasoning with code execution to accurately read analog instruments like pressure gauges. It is now available to developers via the Gemini API and Google AI Studio.

- **[Boston Dynamics Integrates Gemini Robotics-ER 1.6 into Spot](https://roboticsandautomationnews.com/2026/04/15/boston-dynamics-integrates-google-deepminds-gemini-robotics-model-into-spot-inspection-platform/100585/)** - Boston Dynamics partnered with Google Cloud and DeepMind to integrate Gemini Robotics-ER 1.6 into its Orbit software (AIVI and AIVI-Learning systems) used by the Spot robot. The Gemini-powered inspection platform is now live for existing customers, enabling Spot to perform complex reasoning about facility environments — identifying hazards, reading instruments, and providing higher-order visual analysis — going beyond basic object recognition.

## Developer Tools & Vibe Coding
- **[GitHub Copilot CLI v1.0.28 Ships Today](https://github.com/github/copilot-cli/releases)** - GitHub Copilot CLI released version 1.0.28 on April 16, fixing permission prompts to show the correct repository path inside git submodules, removing redundant background agent completion notifications, and simplifying the rewind picker to arrow-key navigation. The MCP migration hint now links to documentation with platform-specific instructions rather than embedding inline shell commands, and Azure resource IDs no longer trigger false path security warnings.

- **[GitHub Copilot to Use Interaction Data for Training Starting April 24](https://www.reddit.com/r/github/comments/1s3kvms/starting_april_24_2026_github_will_begin_using/)** - GitHub announced that starting April 24, 2026, Copilot interactions (inputs, outputs, code snippets) may be used to train and improve AI models by default. Users who previously opted out have their preference retained. GitHub says it has already tested this with Microsoft interaction data and seen meaningful improvements in code acceptance rates. Developers should review their privacy settings before the change takes effect.

- **[Cursor 3 Ships Composer 2, a From-Scratch Frontier Coding Model](https://neuronad.com/cursor-vs-windsurf/)** - Released in April 2026, Cursor 3 introduces Composer 2 — Anysphere's proprietary frontier coding model trained from scratch (not a fine-tune), scoring 61.3 on CursorBench (a 39% improvement over Composer 1.5) and running at 200+ tokens/sec via custom GPU kernels. Cursor has hit $2 billion ARR and is now valued at up to $60 billion; it is tied with Claude Code at 18% developer workplace adoption per JetBrains' January 2026 survey.
