# AI Daily Digest - 2026-04-16

## Anthropic

- **[Claude Opus 4.7 Launches — Most Capable GA Model for Agentic Coding](https://docs.anthropic.com/en/release-notes/overview)** - Anthropic released Claude Opus 4.7, its most capable generally available model for complex reasoning and agentic coding, at the same $5/$25 per MTok pricing as Opus 4.6. The new model brings notable improvements in advanced software engineering — particularly on the hardest coding tasks — along with better vision, sharper instruction following, new effort controls, task budgets, and Claude Code review tools. Early testers report that Opus 4.7 catches logical faults during planning and accelerates execution in async workflows, CI/CD, and long-running automation tasks.

- **[Claude Code Update: /tui Fullscreen, Mobile Push Notifications & More](https://releasebot.io/updates/anthropic/claude-code)** - Claude Code shipped a wide-ranging update (first seen Apr 16) adding a `/tui` command for flicker-free fullscreen rendering, a push notification tool so Claude can alert you on mobile when Remote Control tasks complete, a new `/focus` command, and an `autoScrollEnabled` config. The same release fixes a long list of MCP, session, editor action, and performance issues, continuing the rapid weekly cadence of Claude Code improvements.

- **[Claude Sonnet 4 & Opus 4 Deprecated — Retirement June 15, 2026](https://docs.anthropic.com/en/about-claude/model-deprecations)** - Anthropic announced the deprecation of `claude-sonnet-4-20250514` and `claude-opus-4-20250514`, with API retirement scheduled for June 15, 2026. Developers are recommended to migrate to Claude Sonnet 4.6 and Claude Opus 4.6 (or the newly launched Opus 4.7) respectively.

## OpenAI

- **[OpenAI Codex Major Update: Computer Use, Image Gen, Memory & 111 New Plugins](https://www.theverge.com/ai-artificial-intelligence/913034/openai-codex-updates-use-macos)** - OpenAI shipped a sweeping update to its Codex agentic coding platform today (Apr 16), adding computer use so Codex agents can operate macOS desktop apps in the background without disrupting the developer's own workflow. The update also adds image generation via gpt-image-1.5, an in-app browser with page-level commenting for precise frontend feedback, persistent memory across sessions, proactive task suggestions, and 111 new plugins for tools like GitLab, Atlassian Rovo, and the Microsoft Suite. OpenAI framed this as "building the super app out in the open," previewing its planned unified ChatGPT + Codex + Atlas desktop experience.

- **[OpenAI Agents SDK Gets Sandbox Execution & Long-Horizon Harness](https://www.helpnetsecurity.com/2026/04/16/openai-agents-sdk-harness-and-sandbox-update/)** - OpenAI updated its Agents SDK with a model-native harness and native sandbox execution for safer file, tool, and code workflows. The new harness includes configurable memory, sandbox-aware orchestration, Codex-like filesystem tools, and standardized integrations with primitives including MCP tool use, skills, AGENTS.md custom instructions, and the `apply_patch` tool. The update launches in Python first, with TypeScript support and subagent/code-mode features to follow.

## Google AI

- **[Google DeepMind Launches Gemini Robotics-ER 1.6 with Enhanced Spatial Reasoning](https://siliconangle.com/2026/04/15/deepmind-launches-gemini-robotics-er-1-6-meet-precise-physical-ai-demands/)** - Google DeepMind released Gemini Robotics-ER 1.6 on April 14, a major upgrade to its embodied reasoning model that gives robots advanced spatial awareness and the ability to read analog instruments such as pressure gauges and sight glasses — key for industrial environments. The model uses agentic vision combining visual reasoning with code execution, and can call Google Search, trigger vision-language-action models, and execute custom third-party functions. Developers can access it immediately via the Gemini API and Google AI Studio; Boston Dynamics simultaneously announced integration of the model into its Spot inspection platform via its Orbit software.

- **[Boston Dynamics Integrates Gemini Robotics-ER 1.6 into Spot Inspection Platform](https://roboticsandautomationnews.com/2026/04/15/boston-dynamics-integrates-google-deepminds-gemini-robotics-model-into-spot-inspection-platform/100585/)** - Boston Dynamics partnered with Google Cloud and Google DeepMind to integrate Gemini and Gemini Robotics-ER 1.6 into its Orbit software, powering the AIVI and AIVI-Learning systems on its Spot robot. The integration enables Spot to perform higher-order reasoning about facilities — detecting hazards, answering facility questions from visual data, and automating tasks previously requiring human workers across multiple shifts. The Gemini-powered AIVI-Learning system went live for existing Orbit customers as part of this rollout.

## Developer Tools & Vibe Coding

- **[OpenAI Codex Becomes an AI "Super App" Foundation for Developers](https://www.engadget.com/ai/openais-latest-codex-update-builds-the-groundwork-for-its-upcoming-super-app-170000019.html)** - Today's Codex update (Apr 16) is the biggest single release from OpenAI in the developer tools space this year, directly targeting Claude Code's momentum. Computer use lets multiple Codex agents run in parallel on macOS, the built-in browser supports page-level commenting for frontend iteration, and memory lets Codex accumulate knowledge of each developer's stack and preferences over time. OpenAI head of Codex Thibault Sottiaux described it as "building the super app out in the open," signaling this is a stepping stone to the unified ChatGPT + Codex + Atlas desktop app.

- **[Windsurf (Cognition) Keeps Pushing SWE-1.5 Speed Advantage in AI IDE Race](https://neuronad.com/windsurf-vs-cursor/)** - Windsurf's Wave 13 update (under Cognition AI ownership) brought free SWE-1.5 model access and parallel agents to all tiers. SWE-1.5 runs on Cerebras wafer-scale hardware at 950 tokens/second — roughly 6x faster than Haiku 4.5 and 13x faster than Sonnet 4.5 — making iterative vibe-coding workflows materially faster. Cursor ($2B ARR) remains the market leader for agent infrastructure depth, while Copilot holds 29% enterprise adoption; the race is increasingly about workflow integration and context management rather than raw model quality.

- **[Claude Code Advisor Tool Hits Public Beta for Multi-Model Agentic Workloads](https://docs.claude.com/en/release-notes/overview)** - Anthropic's advisor tool hit public beta on the Claude Developer Platform, allowing developers to pair a fast executor model with a high-intelligence advisor model that provides strategic guidance mid-generation. Long-horizon agentic workloads get close to advisor-only quality while most token generation runs at executor-model rates — a cost-efficiency play for production coding agents.
