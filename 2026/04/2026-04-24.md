# AI Daily Digest - 2026-04-24

## Anthropic

- **[Anthropic & NEC Partner to Build Japan's Largest AI Engineering Workforce](https://www.anthropic.com/news/anthropic-nec)** - Announced today (Apr 24), NEC Corporation becomes Anthropic's first Japan-based global partner, deploying Claude to approximately 30,000 NEC Group employees worldwide. The pair will jointly develop secure, industry-specific AI solutions for Japan's finance, manufacturing, and local government sectors, and NEC will leverage Claude Code to build one of Japan's largest AI-native engineering teams. NEC will also use Claude Cowork internally under its "Client Zero" initiative and establish an internal Center of Excellence for AI talent development.

- **[Anthropic Fixes Claude Code Quality Issues, Resets Usage Limits](https://releasebot.io/updates/anthropic)** - Anthropic traced a cluster of quality complaints to three separate bugs introduced over the past month: a caching issue that dropped thinking history, a reverted verbosity prompt change that hurt coding quality, and reduced reasoning effort defaults. All three were resolved as of April 20 (v2.1.116), with usage limits reset for subscribers. Notably, back-testing with Claude Opus 4.7 found the root-cause bug in a code review — a capability that Opus 4.6 missed.

- **[Anthropic Tests Removing Claude Code from Pro Plan](https://www.theregister.com/2026/04/22/anthropic_removes_claude_code_pro/)** - Anthropic quietly updated its pricing page to show Claude Code excluded from the $20/month Pro plan, triggering developer backlash. The company's head of growth clarified this is a small experiment affecting only ~2% of new prosumer signups, with existing Pro and Max subscribers unaffected. The move reflects how dramatically per-subscriber usage has shifted since Claude Code, Cowork, and long-running async agents became everyday workflows.

- **[Claude Code Rapid-Fire Updates: Speed, MCP, and Session Improvements](https://releasebot.io/updates/anthropic/claude-code)** - This week's Claude Code releases (spotted Apr 21-22) include up to 67% faster `/resume` on large sessions, quicker MCP startup with deferred resource templates, smoother fullscreen scrolling in VS Code/Cursor/Windsurf terminals, and an inline thinking spinner replacing the separate hint row. An earlier drop added model-selection persistence across restarts and smarter stale-session summarization on `/resume`.

## OpenAI

- **[Introducing GPT-5.5 — OpenAI's Smartest Model Yet](https://openai.com/index/introducing-gpt-5-5/)** - OpenAI launched GPT-5.5, its most capable model, rolling it out to Plus, Pro, Business, and Enterprise users in ChatGPT and Codex. The model is both more intelligent and more token-efficient than GPT-5.4, reaching higher-quality outputs with fewer tokens and fewer retries on complex tasks. In Codex specifically, GPT-5.5 handles large-scale engineering work — implementation, refactors, debugging, testing — with stronger context retention across big codebases; the API rollout is coming very soon.

- **[Codex Scales to 4M Weekly Developers; OpenAI Launches Codex Labs with GSI Partners](https://openai.com/index/scaling-codex-to-enterprises-worldwide/)** - OpenAI announced that Codex now serves more than 4 million weekly active developers — up from 3 million just two weeks prior — and launched Codex Labs alongside major global system integrators including Accenture, Capgemini, Cognizant, Infosys, PwC, and TCS to accelerate enterprise adoption. Real-world deployments span Virgin Atlantic (test coverage), Ramp (code review), Notion (feature building), Cisco (large-repo reasoning), and Rakuten (incident response). Workspace Agents, which extend Codex into non-engineering functions, will move to credit-based pricing starting May 6, 2026.

- **[Codex for (Almost) Everything — Computer Use, Memory, 90+ Plugins](https://openai.com/index/codex-for-almost-everything/)** - The Apr 16 Codex update (still rolling out) added background computer use on macOS so Codex can click and type with its own cursor while you work, an in-app browser for iterating on frontend builds, image generation via gpt-image-1.5, context-aware memory, and more than 90 new plugins covering GitHub, Slack, GitLab, Atlassian Rovo, CircleCI, Render, and Microsoft Suite. Personalization and EU/UK rollout are coming in the weeks ahead.

## Google AI

- **[Google Cloud Next '26: Gemini Enterprise Agent Platform, 8th-Gen TPUs, $750M Partner Fund](https://cloud.google.com/blog/topics/google-cloud-next/welcome-to-google-cloud-next26)** - At Cloud Next '26 (Apr 22, Las Vegas), Google rebranded Vertex AI as the Gemini Enterprise Agent Platform — described as an "end-to-end system for the agentic era" — and absorbed Agentspace into a unified Gemini Enterprise product with a new Agent Designer, long-running agents, Workspace Studio (no-code agent builder), and a new A2A inter-agent communication protocol. Two new 8th-generation TPUs were unveiled for training and inference, and Google committed a $750 million fund to accelerate partner agentic AI deployments with firms like Accenture, Deloitte, and McKinsey. Sundar Pichai noted that 75% of all new Google code is now AI-generated, up from 50% last fall.

- **[Deep Research and Deep Research Max Launch in Gemini API](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google released two upgraded autonomous research agents built on Gemini 3.1 Pro (which scores 85.9 on BrowseComp, over 25 points higher than Gemini 3 Pro): Deep Research (optimized for speed/low-latency in user-facing apps) and Deep Research Max (maximum comprehensiveness for async/batch workflows like overnight due-diligence reports). Both support MCP for connecting to internal data sources, file uploads (spreadsheets, videos), and now natively generate charts and infographics inline — a first for the Gemini API. Available now as `deep-research-preview-04-2026` and `deep-research-max-preview-04-2026` in the API; not yet in the Gemini consumer app.

- **[Gemini API Changelog: Gemma 4, Veo 3.1 Lite, Robotics ER 1.6, Flash TTS](https://ai.google.dev/gemini-api/docs/changelog)** - The Gemini API saw a flurry of model releases this week: Gemma 4 (26B and 31B variants on AI Studio and the API), Veo 3.1 Lite Preview (cost-efficient video generation for rapid iteration), Gemini 3.1 Flash TTS Preview (expressive, steerable text-to-speech), and Gemini Robotics-ER 1.6 (updated with instrument reading and improved spatial/physical reasoning). Flex and Priority inference tiers were also introduced to let developers optimize for cost or latency.

## Developer Tools & Vibe Coding

- **[SpaceX Secures $60B Option to Acquire Cursor; Partnership Kicks Off Now](https://www.cnbc.com/2026/04/21/spacex-says-it-can-buy-cursor-later-this-year-for-60-billion-or-pay-10-billion-for-our-work-together.html)** - In the week's biggest developer-tools bombshell, SpaceX announced it preempted Cursor's in-progress $2B fundraise with a landmark deal: Cursor gives SpaceX the right to acquire it later this year for $60 billion, or SpaceX pays $10 billion for joint AI coding work. The partnership pairs Cursor's IDE and developer distribution with SpaceX's Colossus supercomputer (equivalent to 1 million NVIDIA H100s) to build next-generation coding and knowledge-work AI, with Cursor CEO Michael Truell citing plans to "scale up Composer." Microsoft had also reportedly looked at buying Cursor before passing, and Polymarket currently places acquisition odds at ~73.5%.

- **[Cursor BugBot Updated; Background Cloud Agents Now Available](https://neuronad.com/cursor-vs-windsurf/)** - Cursor 3's BugBot received an April 2026 update that learns from pull-request feedback to create and promote review rules, improving automated code review over time. The tool's background cloud agents can now be triggered from GitHub PRs, Linear issues, Slack messages, or the Cursor mobile app — running in isolated VMs with full dev-toolchain access while the developer works locally. Cursor's parent Anysphere has hit $2 billion ARR, and both Cursor and Claude Code sit at 18% developer workplace adoption each per a JetBrains January 2026 survey.

- **[Windsurf Arena Mode Live Leaderboard Hits Thousands of Votes](https://ucstrategies.com/news/windsurf-guide-free-ai-coding-tool-specs-benchmarks-vs-cursor-2026/)** - Windsurf's Arena Mode — which lets developers pit two models side-by-side on real codebase tasks and vote on the winner — has accumulated thousands of real developer votes on its public leaderboard as of April 2026. Windsurf's proprietary SWE-1.5 model posts 40.08% on SWE-Bench at 950 tokens/second generation speed. The tool serves over 1 million users and remains free at the individual tier, though its long-term roadmap is under scrutiny following Cognition AI's $250M acquisition.
