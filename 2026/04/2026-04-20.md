# AI Daily Digest - 2026-04-20

## Anthropic

- **[Claude Opus 4.7 Launches with 3× Vision Resolution and xhigh Effort Level](https://www.anthropic.com/news)** - Anthropic released Claude Opus 4.7 on April 16, delivering improved software engineering performance and a major jump in vision capability — images can now be processed at up to 2,576 pixels on the long edge, triple the previous limit. On coding benchmarks, Opus 4.7 scores 70% on CursorBench (vs. 58% for 4.6), resolves 3× more production tasks on Rakuten-SWE-Bench, and achieves 87.6% on SWE-bench Verified. A new xhigh effort level sits between `high` and `max`, giving developers five granular effort tiers, and task budgets for agentic runs entered public beta. The model is available on Claude API, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry.

- **[Claude Design Debuts in Research Preview — Figma Stock Falls 7%](https://techcrunch.com/2026/04/17/anthropic-launches-claude-design-a-new-product-for-creating-quick-visuals/)** - Anthropic launched Claude Design on April 17, an Anthropic Labs product that lets anyone produce prototypes, slides, one-pagers, and full design systems by describing what they want in plain English, all powered by Claude Opus 4.7. The tool reads a team's existing codebase and design files during onboarding to automatically build a persistent design system — colors, typography, and components applied consistently across every future project. Designs can be exported as PDF, PPTX, HTML, or pushed directly to Canva; a one-command handoff to Claude Code bridges the prototype-to-production gap. Figma's stock dropped 7.28% on the day of the announcement, with Adobe falling ~1.5%, as investors assessed Anthropic's move into the $60B design-software market.

- **[Claude Code Gets Auto Mode, Routines, and Rebuilt Desktop App](https://www.macrumors.com/2026/04/15/anthropic-rebuilds-claude-code-desktop-app-around-parallel-sessions/)** - The Claude Code desktop app received a major redesign, adding a sidebar for managing multiple parallel sessions, drag-and-drop pane layouts, an integrated terminal, in-app file editor, rebuilt diff viewer, and expanded preview pane for HTML and PDFs. Separately, Anthropic shipped Routines — a way to bundle a prompt, a repo, and connectors into a single configuration that can run on a schedule, trigger off a GitHub event, or fire via API call, running on Claude Code's web infrastructure even without an active local session. Auto mode is now available for Max subscribers when using Opus 4.7, and the new /ultrareview flag enables deeper code review passes.

- **[Claude Managed Agents Enters Public Beta](https://platform.claude.com/docs/en/release-notes/overview)** - Anthropic launched Claude Managed Agents in public beta, a fully managed agent harness for running Claude as an autonomous agent with secure sandboxing, built-in tools, and server-sent event streaming. Developers can create agents, configure containers, and run sessions through the API using the managed-agents-2026-04-01 beta header. Anthropic also launched the `ant` CLI, a command-line client for the Claude API offering faster interaction, native Claude Code integration, and YAML-based versioning of API resources.

- **[Anthropic Commits Claude Will Stay Ad-Free](https://www.anthropic.com/news)** - Anthropic published a blog post this week explaining why Claude will remain ad-free, arguing that advertising incentives are fundamentally incompatible with a genuinely helpful AI assistant. The company outlined how it plans to expand access and grow revenue through subscriptions and API usage without compromising user trust — a pointed contrast to rivals rolling out ad-supported tiers.

## OpenAI

- **[Codex Becomes a Full AI Workspace: Computer Use, Memory, and 90+ Plugins](https://openai.com/index/codex-for-almost-everything/)** - OpenAI shipped a sweeping Codex update on April 16 for its 3-million-plus weekly developer users, expanding the product far beyond coding assistance. Background computer use now lets Codex operate any macOS desktop app autonomously — seeing, clicking, and typing with its own cursor — while multiple agents can run in parallel without interfering with your own work. An in-app browser lets users annotate pages directly to give the AI precise frontend instructions; image generation via gpt-image-1.5 is now built-in; memory retains project conventions and preferences across sessions; and automations can now schedule and resume tasks across days or weeks. More than 90 new plugins — including Atlassian Rovo, CircleCI, CodeRabbit, GitLab Issues, Microsoft Suite, Neon by Databricks, and Render — expand Codex's reach across the full dev toolchain.

- **[OpenAI Agents SDK Gets Long-Horizon Harness and Native Sandboxing](https://openai.com/news/)** - OpenAI's Agents SDK received its most significant update (April 16), adding a model-native harness purpose-built for long-horizon agentic workflows, native sandbox execution for safe file and tool operations, configurable memory, MCP integration, portable workspace support, and snapshotting for durable agent runs. Sandbox providers now include Blaxel, Cloudflare, Daytona, E2B, Modal, Runloop, and Vercel. The update aims to give developers standardized, production-ready infrastructure for multi-step agentic tasks with safety guardrails built in.

- **[GPT-Rosalind Debuts as OpenAI's Life Sciences Reasoning Model](https://openai.com/news/)** - OpenAI introduced GPT-Rosalind on April 16-17, the first in its life sciences model series, optimized for biology, drug discovery, chemistry, protein engineering, and genomics. A companion Codex research plugin connects scientists to 50+ tools and data sources for accelerated research workflows. Amgen is among the early pharma partners applying GPT-Rosalind to drug delivery workflows. OpenAI says the model series will continue expanding biochemical reasoning capabilities across long-horizon, tool-heavy scientific tasks.

## Google AI

- **[Gemini Robotics-ER 1.6 Goes Public — Boston Dynamics Spot Reads Industrial Gauges](https://deepmind.google/blog/gemini-robotics-er-1-6/)** - Google DeepMind released Gemini Robotics-ER 1.6 on April 14-15, a major upgrade to its embodied reasoning model that acts as the strategic "brain" directing robotic systems in physical environments. New capabilities include improved spatial reasoning, multi-view perception, success detection, and a novel instrument-reading feature — developed in partnership with Boston Dynamics — enabling Spot robots deployed across 40+ countries to autonomously read analog gauges, thermometers, and digital readouts in industrial facilities. The model is now publicly available via the Gemini API and Google AI Studio (previously restricted to trusted testers including Agile Robots, Agility Robotics, and Boston Dynamics), with a Colab notebook for rapid integration. DeepMind also notes ER 1.6 is its safest robotics model yet, with improved hazard detection and built-in physical manipulation constraints.

- **[Gemma 4 Launches as Fully Open-Source Model for Android and Local Devices](https://mashable.com/article/google-releases-gemma-4-open-ai-model-now-open-source-how-to-try-it)** - Google released Gemma 4 under a fully open-source Apache 2.0 license — unusual for a frontier-class model — enabling complete developer flexibility for on-premises and cloud deployments. Built from the same research as Gemini 3, Gemma 4 is designed to run on billions of Android devices and compatible laptop GPUs, requiring no internet connection for inference. Google is calling it its most capable open model yet, giving developers full control over data, infrastructure, and model weights.

## Developer Tools & Vibe Coding

- **[OpenAI Codex Adds PR Reviews, SSH Devboxes, and Multi-Agent Parallelism](https://openai.com/index/codex-for-almost-everything/)** - The April 16 Codex update brought a wave of developer-workflow improvements beyond headline computer use: in-app GitHub PR review (inspect diffs, view changed files, respond to review comments), multiple terminal tabs, alpha SSH connections to remote devboxes, and rich artifact previews for PDFs, spreadsheets, and slide decks in the sidebar. Codex can now deploy multiple specialized agents simultaneously — one writing, one testing, one debugging — and supports persistent memory to carry project context across sessions. Rolling out to desktop users signed in with ChatGPT; computer use is initially macOS-only.

- **[GitHub Copilot Agent Mode Reaches General Availability Across VS Code and JetBrains](https://www.digitalapplied.com/blog/ai-coding-assistants-april-2026-cursor-copilot-claude)** - GitHub Copilot's agent mode is now generally available on both VS Code and JetBrains IDEs — a meaningful milestone since it was previously VS Code only. Agent mode handles multi-step coding tasks within the editor autonomously: reading files, generating code, running terminal commands, and iterating on errors without manual re-prompting. Agentic code review shipped in March 2026, and semantic code search now finds conceptually related code rather than just keyword matches, rounding out Copilot's evolution from autocomplete tool into a full agentic coding assistant.

- **[Vibe Coding Tool Ecosystem: Cursor + Claude Code Emerge as Dominant Stack](https://www.digitalapplied.com/blog/ai-coding-assistants-april-2026-cursor-copilot-claude)** - The vibe coding landscape has settled into a multi-tool stack: 95% of developers now use AI tools at least weekly and the average experienced developer uses 2.3 tools simultaneously. Cursor Composer 2 (released March 19, built on Kimi K2.5 with custom RL) scores 61.3 on CursorBench — 37% above Composer 1.5 — and 73.7 on SWE-bench Multilingual. Claude Code has a 46% "most loved" developer rating vs. Cursor at 19% and Copilot at 9%. The most common pro stack is Cursor for daily IDE editing plus Claude Code for complex architectural sessions; v0 and Lovable remain the go-to app-builders for non-developers and rapid frontend prototyping. MCP crossed 97 million installs in March 2026, cementing it as the de facto agent-tooling standard.
