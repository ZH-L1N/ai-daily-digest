# AI Daily Digest - 2026-04-20

## Anthropic

- **[Claude Opus 4.7 Ships GA: 3.75MP Vision, xhigh Effort, and Task Budgets](https://www.anthropic.com/news)** - Anthropic released Claude Opus 4.7 on April 16 as its most capable generally-available model to date, scoring 87.6% on SWE-bench Verified (up from 80.8%) and 70% on CursorBench (up from 58%). The model adds a 3.3× vision resolution bump — images now processed at up to 2,576 px / 3.75 MP versus 1.15 MP previously — and a new xhigh effort level sitting between high and max for Claude Code. Task budgets (beta) let developers give the model a rough token target for an entire agentic loop, with the model wrapping gracefully as the budget approaches. Available at launch on Claude API, Amazon Bedrock (GA in US-East, Tokyo, Ireland, Stockholm), Google Cloud Vertex AI, and Microsoft Foundry at unchanged pricing of $5/$25 per million tokens.

- **[Claude Design Launches in Research Preview — Anthropic Enters the $60B Design-Tool Market](https://techcrunch.com/2026/04/17/anthropic-launches-claude-design-a-new-product-for-creating-quick-visuals/)** - Shipped alongside Opus 4.7 on April 17, Claude Design is an Anthropic Labs product that lets users create prototypes, slides, one-pagers, and full design systems by describing what they need in plain English. Powered by Opus 4.7's high-resolution vision, it can ingest a team's existing codebase and design files to auto-build a persistent design system applied consistently to every future project. Designs export as PDF, PPTX, or HTML, with a one-command bridge to Claude Code. Figma stock fell ~7% and Adobe ~1.5% on the announcement; the product is available in research preview to Pro, Max, Team, and Enterprise subscribers.

- **[Claude Code: Auto Mode, /ultrareview, TUI Overhaul, and Mobile Push Notifications](https://releasebot.io/updates/anthropic)** - Claude Code's latest update adds Auto mode for Max subscribers on Opus 4.7, a new /ultrareview flag for deeper multi-agent code review passes, and a full /tui fullscreen command for flicker-free terminal rendering. A push notification tool lets Claude send mobile alerts when Remote Control is active, and an interactive /effort slider (with arrow-key navigation) lets developers pick from five effort levels including the new xhigh tier. The macOS desktop app received a rebuilt multi-session sidebar, drag-and-drop pane layouts, integrated terminal, and expanded file previews.

- **[Dario Amodei Meets White House Chief of Staff Over Mythos Model](https://www.cnn.com/2026/04/17/business/anthropic-white-house-meeting-dario-amodei)** - Anthropic CEO Dario Amodei met with White House Chief of Staff Susie Wiles on April 17 for discussions described as "productive and constructive," covering collaboration opportunities and safety protocols for scaling AI. The meeting centered partly on Mythos — Anthropic's restricted frontier model announced April 7 under Project Glasswing — which the UK's AI Security Institute called "a step up" and which the U.S. government is planning to make available to federal agencies for defensive cybersecurity. Project Glasswing brings together Amazon, Apple, Google, Microsoft, and JPMorgan Chase to harden critical software against vulnerabilities the model can identify.

## OpenAI

- **[Codex Becomes a Full AI Workspace: Computer Use, Memory, and 90+ Plugins](https://openai.com/index/codex-for-almost-everything/)** - OpenAI shipped a major Codex update on April 16 — dubbed "Codex for (almost) everything" — for its 3 million+ weekly developer users. Background computer use now lets Codex operate any macOS desktop app autonomously with its own cursor, with multiple agents running in parallel. An in-app browser lets users annotate pages directly for precise frontend instructions; image generation via gpt-image-1.5 is built in; memory retains project conventions across sessions; and automations can schedule and resume tasks across days or weeks. Over 90 new plugins — Atlassian Rovo, CircleCI, CodeRabbit, GitLab Issues, Microsoft Suite, Neon by Databricks, Render — expand its reach across the full dev toolchain. Codex lead Thibault Sottiaux confirmed: "We're doing the sneaky thing where we're building the super app out in the open and evolving it out of Codex."

- **[OpenAI Agents SDK Gets Model-Native Harness and Native Sandbox Execution](https://openai.com/index/the-next-evolution-of-the-agents-sdk/)** - The April 16 Agents SDK update adds a model-native harness for long-horizon agentic workflows — configurable memory, sandbox-aware orchestration, Codex-like filesystem tools, MCP integration via tool use, file edits via apply_patch, and shell execution. A new native sandbox (UnixLocalSandboxClient) isolates agent execution from host systems, keeping credentials and orchestration outside model-generated code. Early adopters report 40% cost savings over custom runtimes. TypeScript support and subagent patterns are planned; the update is generally available at standard API pricing.

- **[GPT-Rosalind Debuts as OpenAI's Dedicated Life-Sciences Reasoning Model](https://openai.com/news/)** - Introduced April 16, GPT-Rosalind is the first in OpenAI's life sciences model series, optimized for biology, drug discovery, chemistry, protein engineering, and genomics. A companion Codex research plugin connects scientists to 50+ tools and data sources. Amgen is an early partner applying GPT-Rosalind to drug delivery workflows. OpenAI says the model series will expand biochemical reasoning capabilities over long-horizon, tool-heavy scientific tasks.

- **[ChatGPT and Codex Partial Outage Hits Users Globally on April 20](https://ftw-eu.usatoday.com/story/tech/2026/04/20/is-chatgpt-down-today-latest-updates/89700179007/)** - On the morning of April 20, ChatGPT and Codex experienced a significant partial outage with over 7,600 reports in the UK and 1,700+ in the US at peak. OpenAI's status page flagged "users unable to load ChatGPT and Codex" affecting conversations, login, voice mode, and image generation. The incident was upgraded to "partial outage" status before service was gradually restored; the outage underscored how central ChatGPT has become as a daily productivity tool.

## Google AI

- **[Gemini Robotics-ER 1.6 Goes Public — Boston Dynamics Spot Reads Industrial Gauges](https://deepmind.google/blog/gemini-robotics-er-1-6/)** - Google DeepMind released Gemini Robotics-ER 1.6 on April 14-15, an upgrade to its embodied reasoning model that acts as the strategic "brain" for robotic systems. New capabilities include improved spatial reasoning, multi-view perception, success detection, and instrument reading — developed with Boston Dynamics — enabling Spot robots in 40+ countries to autonomously read analog gauges, thermometers, and digital readouts in industrial facilities. The model is now publicly available via the Gemini API and Google AI Studio (previously restricted to trusted testers). DeepMind describes ER 1.6 as its safest robotics model, with improved hazard detection scoring +6% on text and +10% on video injury-risk perception versus Gemini 3.0 Flash.

- **[Google DeepMind VP Showcases Gemini Embeddings 2 at AIE Europe (April 20)](https://www.startuphub.ai/ai-news/artificial-intelligence/2026/google-deepmind-vp-on-ai-s-future-of-intelligence)** - Raia Hadsell, VP of Research at Google DeepMind and UK AI Ambassador, presented at AI Engineer Europe today, highlighting Gemini Embeddings 2 — a fully omnimodal model that maps text, images, video, audio, and PDFs into a single unified semantic vector space. Hadsell described it as "bordering on magical" for eliminating lossy intermediate steps like OCR and transcription. The model, available in preview on Vertex AI and the Gemini API, tops benchmarks across modalities and spans 100+ languages, inheriting Gemini's multimodal architecture for high-value retrieval applications.

- **[AWS Weekly Roundup: Claude Opus 4.7 Now Live in Amazon Bedrock](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-claude-opus-4-7-in-amazon-bedrock-aws-interconnect-ga-and-more-april-20-2026/)** - Amazon's April 20 weekly roundup confirms Claude Opus 4.7 is live in Bedrock with up to 10,000 requests per minute per account per region, running on Bedrock's next-generation inference engine with dynamic capacity allocation and adaptive thinking. The model scores 64.3% on SWE-bench Pro and adds high-resolution image support for improved accuracy on charts, dense documents, and screen UIs. Bedrock also launched granular cost attribution for inference calls by IAM principal, making per-team and per-project AI spend tracking possible.

## Developer Tools & Vibe Coding

- **[GitHub Copilot Rolls Out Claude Opus 4.7 on Copilot Pro+](https://github.blog/changelog/2026-04-16-claude-opus-4-7-is-generally-available/)** - Claude Opus 4.7 is now rolling out on GitHub Copilot, replacing Opus 4.5 and 4.6 in the model picker for Copilot Pro+ users. GitHub's testing found stronger multi-step task performance, more reliable agentic execution, and meaningful improvement in long-horizon reasoning. The model launches with a 7.5× premium request multiplier as promotional pricing through April 30; Copilot now has 4.7 million paid subscribers and 90% Fortune 100 adoption.

- **[Vibe Coding Stack Hardens: Cursor + Claude Code Lead, MCP Crosses 97M Installs](https://tokenmix.ai/blog/vibe-coding-guide-2026)** - As of April 2026, 95% of developers use AI tools at least weekly and the average experienced developer runs 2.3 tools simultaneously. The dominant pro stack is Cursor for IDE editing plus Claude Code for complex architectural sessions; v0 and Lovable serve non-developers and frontend prototyping. Windsurf (acquired by Cognition for $250M after Google poached its founding team for $2.4B) remains strong for budget-conscious developers with its free tier and Cascade autonomous agent. MCP crossed 97 million installs in March 2026, cementing it as the de facto standard for agent tooling — a signal that agentic infrastructure is maturing fast.

- **[Forbes 2026 AI 50: Cursor, Lovable, and Replit Named Alongside Lab Giants](https://www.forbes.com/sites/pr/2026/04/16/forbes-unveils-2026-ai-50-marking-shift-from-ai-dominance-to-ai-independence/)** - Forbes released its 2026 AI 50 list on April 16, highlighting a shift from raw model power toward control, cost, and real-world deployment. Twenty newcomers made the list — including Lovable, Cognition, Black Forest Labs, and Reflection AI — reflecting how quickly the application layer is maturing.
