# AI Daily Digest - 2026-04-20

## Anthropic

- **[Claude Opus 4.7 Now Generally Available](https://www.anthropic.com/news)** - Anthropic has shipped Claude Opus 4.7 as a GA upgrade, delivering stronger software engineering performance, higher-resolution vision, and more reliable long-running agent work. Users report being able to hand off their hardest coding tasks — the kind that previously needed close supervision — with confidence. Claude Code simultaneously gained Auto mode for Max subscribers plus a new `xhigh` effort level and an interactive `/effort` slider.

- **[Claude Design Launches as New Anthropic Labs Product](https://techcrunch.com/2026/04/17/anthropic-launches-claude-design-a-new-product-for-creating-quick-visuals/)** - Anthropic introduced Claude Design, an experimental product for generating visual outputs like prototypes, slides, and one-pagers from natural language. Designed to complement (not replace) tools like Canva, it reads a company's codebase and design files to apply consistent brand styles, and exports to PDF, PPTX, or Canva. The launch marks Anthropic's push into the prosumer design-tool market.

- **[Claude Managed Agents Enters Public Beta](https://platform.claude.com/docs/en/release-notes/overview)** - Anthropic launched Claude Managed Agents in public beta — a fully managed agent harness that runs Claude autonomously with secure sandboxing, built-in tools, and server-sent event streaming. Separately, Claude Code shipped a crash fix (April 19) for a permission dialog bug that triggered when a teammate requested tool permission in agent teams.

- **[Claude Mythos Preview: Project Glasswing Cybersecurity Initiative](https://red.anthropic.com/2026/mythos-preview/)** - Claude Mythos Preview, a new general-purpose model with exceptional computer-security capabilities, is available as an invitation-only research preview for defensive cybersecurity work. Under Project Glasswing, it found thousands of vulnerabilities in operating systems and browsers — including a fully autonomous exploit of a 17-year-old remote code execution flaw in FreeBSD — raising the bar (and the stakes) for AI-assisted security research.

## OpenAI

- **[Codex Gets Major Expansion: Computer Use, Memory, and 90+ Plugins](https://openai.com/index/codex-for-almost-everything/)** - OpenAI shipped "Codex for (almost) everything" on April 16, transforming the coding agent used by 3 million weekly developers into a full-lifecycle AI workspace. Background computer use lets Codex operate Mac apps autonomously with its own cursor while you keep working; memory retains preferences and project conventions across sessions; and 90+ new plugins (Atlassian Rovo, CircleCI, GitLab Issues, Microsoft Suite, and more) expand its reach across the dev toolchain. An in-app browser enables direct page annotation, and automations can now schedule and resume work across days or weeks.

- **[OpenAI Agents SDK Evolves with Sandboxing and Long-Horizon Harness](https://openai.com/index/the-next-evolution-of-the-agents-sdk/)** - The Agents SDK received its most significant update yet (April 16), introducing a model-native harness for long-horizon multi-step tasks plus native sandbox execution that keeps agents isolated to designated files and code. The harness adds configurable memory, MCP tool-use integration, shell execution, `apply_patch`-style file edits, and snapshotting for durable agent runs. Sandbox providers include Blaxel, Cloudflare, Daytona, E2B, Modal, Runloop, and Vercel; subagents and code mode are coming next.

- **[GPT-Rosalind Debuts for Life Sciences Research](https://openai.com/news/)** - OpenAI introduced GPT-Rosalind (April 16), a frontier reasoning model optimized for biology, drug discovery, and translational medicine. It combines improved tool use with deeper understanding across chemistry, protein engineering, and genomics. A companion Codex research plugin gives scientists access to 50+ tools and data sources. Amgen is among early partners applying it to accelerate drug delivery workflows.

## Google AI

- **[Gemini Robotics-ER 1.6 Released — Boston Dynamics Integration Goes Live](https://deepmind.google/blog/gemini-robotics-er-1-6/)** - Google DeepMind released Gemini Robotics-ER 1.6, a major upgrade to its embodied reasoning model that serves as the "cognitive brain" for autonomous robots. New capabilities include improved spatial reasoning, multi-view perception, and a novel instrument-reading feature (developed with Boston Dynamics) that lets Boston Dynamics' Spot read analog gauges, thermometers, and digital readouts in industrial facilities. The model is now publicly available via the Gemini API and Google AI Studio — previously limited to trusted testers — with a Colab notebook for quick integration.

- **[Gemini 3 Deep Think Upgraded for Science and Engineering](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a major upgrade to Gemini 3 Deep Think (April 15), its specialized reasoning mode built for science, research, and engineering challenges. Early results include identifying a subtle logical flaw in a mathematics paper that passed human peer review, and achieving gold-medal-level results on the 2025 International Physics and Chemistry Olympiads. Available now for Google AI Ultra subscribers in the Gemini app; researchers and enterprises can request early API access.

## Developer Tools & Vibe Coding

- **[Claude Code Routines: Scheduled Automations That Run Without Your Mac](https://9to5mac.com/2026/04/14/anthropic-adds-repeatable-routines-feature-to-claude-code-heres-how-it-works/)** - Anthropic added repeatable Routines to a redesigned Claude Code, letting developers schedule automations (GitHub workflows, API tasks, cron-style triggers) that run on Claude's cloud infrastructure even when their Mac is offline. The redesigned Claude Code app also now supports multiple side-by-side sessions in one window, an integrated terminal, file editing, HTML/PDF preview, and a drag-and-drop layout — all part of a unified Claude app alongside Cowork and Chat.

- **[Vibe Coding in 2026: The Ecosystem Matures](https://tokenmix.ai/blog/vibe-coding-guide-2026)** - The vibe coding tool landscape continues to diverge into two clear categories: AI app builders (Lovable, Bolt.new, Replit, v0) for non-developers spinning up full apps from prompts, and AI coding assistants (Cursor, Windsurf, Claude Code, GitHub Copilot, Gemini CLI) for developers who want deep codebase integration. Cursor dominates for existing codebases and power users; Windsurf (acquired by OpenAI, built on Cascade) offers strong agentic workflows at a lower price; Claude Code leads on code quality and architectural decisions for complex multi-file tasks. MCP crossed 97 million installs in March 2026, cementing it as the de facto agent-tooling contract across the industry.

- **[OpenAI Codex Adds PR Review and SSH Devboxes for Developer Workflows](https://openai.com/index/codex-for-almost-everything/)** - Beyond the headline computer-use feature, Codex's April 16 update also matured its developer-specific tooling: in-app PR review (inspect diffs, respond to GitHub comments), multiple terminal tabs, SSH connections to remote devboxes (alpha), and rich sidebar file previews for PDFs, spreadsheets, and slides. OpenAI is also positioning Codex as a plugin distribution surface where each integration bundles skills, app APIs, and an MCP server — converging on the same architectural pattern as Claude Code and Windsurf.
