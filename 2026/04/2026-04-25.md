# AI Daily Digest - 2026-04-25

## Anthropic

- **[Anthropic & NEC Partner to Build Japan's Largest AI Engineering Workforce](https://www.anthropic.com/news/anthropic-nec)** - Announced April 24, NEC Corporation becomes Anthropic's first Japan-based global partner, deploying Claude across approximately 30,000 NEC Group employees worldwide. The companies will jointly develop secure, industry-specific AI solutions targeting finance, manufacturing, and local government, and NEC will use Claude Code to build one of Japan's largest AI-native engineering teams. NEC is also integrating Anthropic's AI into its Security Operations Center (SOC) services to address increasingly sophisticated cyber threats.

- **[Anthropic Admits It Accidentally Degraded Claude Code Quality](https://www.theregister.com/2026/04/23/anthropic_says_it_has_fixed/)** - Anthropic published a post-mortem on April 23 revealing three compounding changes in March–April caused measurable quality regressions in Claude Code, Claude Agent SDK, and Claude Cowork (the API was not affected). The missteps included lowering default reasoning effort to "medium" (reverted April 7), a cache-optimization bug that made Claude "forgetful and repetitive" (fixed April 10), and an overly strict verbosity system prompt that cut coding quality by ~3% (reverted April 20). As remediation, Anthropic reset usage limits for all affected subscribers and launched a new @ClaudeDevs social account for more transparent developer communication.

- **[Claude Mythos Unauthorized Access Investigation](https://techcrunch.com/2026/04/21/unauthorized-group-has-gained-access-to-anthropics-exclusive-cyber-tool-mythos-report-claims/)** - Bloomberg reported on April 21–22 that a small group of unauthorized users gained access to Claude Mythos Preview — the restricted, highly capable cybersecurity model — on the same day it was publicly announced, by guessing the model's API endpoint and leveraging credentials from a third-party contractor. Anthropic confirmed it is "investigating a report claiming unauthorized access to Claude Mythos Preview through one of our third-party vendor environments" and stated there is no evidence the breach extended to its core systems. The incident raises fresh questions about securing gated AI models, especially one Anthropic itself describes as capable of surpassing skilled humans at finding and exploiting software vulnerabilities.

## OpenAI

- **[OpenAI Launches Codex-Powered Workspace Agents in ChatGPT](https://openai.com/index/introducing-workspace-agents-in-chatgpt/)** - Announced April 22, OpenAI's new Workspace Agents are persistent, Codex-powered AI assistants for business teams that automate complex multi-step workflows and continue operating in the cloud even when users are offline. They integrate directly with Slack, Google Drive, Salesforce, Notion, Atlassian, and other enterprise tools, and replace the older custom GPTs model for organizational use. Workspace Agents are in research preview, free through May 6, 2026, after which credit-based pricing kicks in for ChatGPT Business, Enterprise, Edu, and Teachers plans.

- **[OpenAI Launches Codex Labs to Accelerate Enterprise Adoption](https://releasebot.io/updates/openai)** - OpenAI announced Codex Labs, pairing hands-on workshops and expert working sessions with seven top global systems integrators (Accenture, Capgemini, CGI, Cognizant, Infosys, PwC, and TCS) to help large enterprises integrate Codex into production engineering workflows. The number of weekly Codex developer users has grown from 3 million to over 4 million in just two weeks, with enterprise customers including Virgin Atlantic, Ramp, Notion, Cisco, and Rakuten actively using it across the software development lifecycle.

## Google AI

- **[Google Launches Deep Research and Deep Research Max Agents via Gemini API](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - On April 21, Google DeepMind unveiled two new autonomous research agents built on Gemini 3.1 Pro: Deep Research (optimized for low latency in interactive applications) and Deep Research Max (designed for exhaustive, asynchronous background analysis using extended test-time compute). Both agents support MCP integration to connect to enterprise data sources alongside open-web retrieval, and now natively generate inline charts and infographics within research reports. The agents are available via paid tiers of the Gemini API (Interactions API); notably they are API-only and not yet in the consumer Gemini app.

- **[Accenture & Google Cloud Expand Gemini Enterprise Acceleration Program at Cloud Next '26](https://newsroom.accenture.com/news/2026/accenture-and-google-cloud-expand-partnership-to-scale-agentic-transformation-for-global-enterprises-with-gemini-enterprise)** - At Google Cloud Next '26 (April 22–24, Las Vegas), Accenture and Google Cloud announced the Gemini Enterprise Acceleration Program, a joint initiative combining thousands of AI-skilled engineers, Google forward-deployed engineers, and domain experts to scale agentic AI deployments for enterprise clients. The program provides early access to frontier Google DeepMind models, with Accenture feedback feeding directly into model refinement. Accenture earned Google Cloud's 2026 Global Services Partner of the Year award for the fourth consecutive year.

## Developer Tools & Vibe Coding

- **[GitHub Copilot CLI v1.0.36 Ships UX Improvements](https://www.havoptic.com/tools/github-copilot)** - Released April 24, GitHub Copilot CLI v1.0.36 adds a selection indicator (❯) to the subcommand picker for clarity, along with a clearer error message and direct link when multiple conflicting configurations are detected. Earlier this week (v1.0.35, April 23), the CLI gained tab-completion for slash command arguments and subcommands, and shell escape commands now use the user's `$SHELL` environment variable. These incremental UX improvements continue Copilot CLI's rapid weekly release cadence throughout April 2026.

- **[OpenAI Codex "for (Almost) Everything" — Computer Use, Memory & 90+ Plugins](https://www.buildfastwithai.com/blogs/openai-codex-for-almost-everything-2026)** - OpenAI's April 16 major Codex desktop update added computer use (macOS only at launch), an in-app browser, image generation, persistent memory preview, and 90+ curated plugins including Atlassian Rovo, CircleCI, GitLab, and Microsoft Suite. The update positions Codex more squarely against Claude Code and Cursor as a full-workflow AI development tool, not just a code generator. Within ChatGPT Business and Enterprise, Codex user counts grew 6x between January and April 2026.

- **[Claude Code Ships Visual Vim Modes, Custom Themes & MCP Tool Hooks](https://releasebot.io/updates/anthropic/claude-code)** - A recent Claude Code update (first seen April 23) added visual Vim mode (v) and visual-line mode (V) with operators and selection feedback, unified /cost and /stats into a single /usage command, introduced named custom themes (editable via JSON or /theme), and allowed hooks to invoke MCP tools directly via `type: "mcp_tool"`. A new `DISABLE_UPDATES` environment variable completely blocks all update paths. These improvements come alongside the broader Claude Code quality reset that Anthropic announced April 23.
