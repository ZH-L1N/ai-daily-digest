# AI Daily Digest - 2026-04-27

## Anthropic

- **[Election Safeguards Update: Opus 4.7 & Sonnet 4.6 Score Near-Perfect on Political Balance](https://www.anthropic.com/news/election-safeguards-update)** - Ahead of the 2026 US midterms, Anthropic published detailed election safeguard metrics: Claude Opus 4.7 and Sonnet 4.6 scored 95% and 96% on political impartiality evaluations, and 100%/99.8% compliance with election-related usage policy tests across 600 prompts. For the first time, Anthropic also tested whether models could autonomously run influence operations end-to-end — with safeguards in place, latest models refused nearly every task. Claude.ai will surface election banners directing users to TurboVote for the US midterms.

- **[Anthropic & NEC Partner to Build Japan's Largest AI Engineering Workforce](https://www.anthropic.com/news/anthropic-nec)** - Announced April 24, Anthropic and NEC are collaborating to scale Japan's AI engineering talent base, the largest such initiative in the country. The deal is part of Anthropic's broader international expansion push as it grows beyond $30B annualized revenue run rate.

- **[Claude Code Quality Fixes + Usage Limits Reset (v2.1.116)](https://www.anthropic.com/news)** - Anthropic acknowledged three separate issues that degraded Claude Code quality over the past month: a downgraded default reasoning effort (reverted April 7), a caching bug that made Claude forget its own thinking history in resumed sessions (fixed April 10), and a verbosity system prompt change that hurt coding quality (reverted April 20). All three are resolved as of v2.1.116, and usage limits were reset for subscribers. Notably, Opus 4.7 (used in Code Review) caught the caching bug in retrospective testing while Opus 4.6 did not.

- **[Anthropic Tests Removing Claude Code from Pro Plan — Then Reverses](https://www.theregister.com/2026/04/22/anthropic_removes_claude_code_pro/)** - On April 22, Anthropic's pricing page quietly dropped Claude Code as a Pro plan feature, triggering developer backlash. Head of Growth Amol Avasare clarified it was a test affecting ~2% of new prosumer signups, and existing subscribers were unaffected. The public-facing page change was reverted. Avasare acknowledged the product's usage patterns have fundamentally changed since agent workflows became mainstream, and that plan restructuring may come with proper advance notice.

## OpenAI

- **[Introducing GPT-5.5: Available in ChatGPT, Codex, and Now the API](https://openai.com/index/introducing-gpt-5-5/)** - Released April 23 and available via API as of April 24, GPT-5.5 is OpenAI's strongest model to date, described as "smarter and more intuitive" with major gains in agentic coding, computer use, knowledge work, and early scientific research. On Terminal-Bench 2.0, it achieves 82.7% accuracy. It matches GPT-5.4 per-token latency while performing at a higher intelligence level, and uses significantly fewer tokens on Codex tasks. GPT-5.5 is live for Plus, Pro, Business, and Enterprise users in ChatGPT and Codex; GPT-5.5 Pro goes to Pro/Business/Enterprise. OpenAI president Greg Brockman framed it as a step toward a unified AI "super app" combining ChatGPT, Codex, and an AI browser.

- **[GPT-5.5 Bio Bug Bounty Program Launched](https://letsdatascience.com/news/openai-launches-gpt-55-bio-bug-bounty-program-0b56430d)** - OpenAI opened an invite-only biosafety bounty program targeting a single universal jailbreak that could produce harmful biological outputs from GPT-5.5 in Codex Desktop. Applications run April 23 – June 22, with testing from April 28 – July 27, 2026. Top prize is $25,000. The program is restricted to vetted red-teamers and biosecurity researchers under NDA, reflecting OpenAI's proactive stance on dual-use risks as models gain deeper domain competence.

- **[Codex Changelog: GPT-5.5 Now Default, In-App Browser Control, Permission Profile Overhaul](https://developers.openai.com/codex/changelog)** - GPT-5.5 is now the recommended default in all Codex surfaces (app, CLI, IDE extension). The Codex app can now let the model operate a built-in browser for local dev servers and visual bug reproduction. Permission profiles now round-trip across TUI sessions, user turns, MCP sandbox state, and shell escalation, giving enterprise teams tighter security controls.

## Google AI

- **[Google Cloud Next '26: Gemini Enterprise Agent Platform, 8th-Gen TPUs, $750M Partner Fund](https://cloud.google.com/blog/topics/google-cloud-next/welcome-to-google-cloud-next26)** - Google's flagship developer conference (April 22–24, Las Vegas, 32,000+ attendees) centered on the "agentic era." Key product launches included: the **Gemini Enterprise Agent Platform** (renaming/unifying Vertex AI with new Agent Designer, Agent-to-Agent Orchestration, Agent Registry, Agent Inbox, and long-running background agents); **8th-generation TPUs** with two chips — TPU 8t for training (up to 9,600 TPUs in a superpod) and TPU 8i for inference (80% better performance per dollar); and a **$750 million partner fund** to accelerate agentic AI adoption across Google's 120,000-member partner ecosystem. Sundar Pichai noted 75% of all new Google code is now AI-generated.

- **[Google Launches Deep Research & Deep Research Max on Gemini 3.1 Pro](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Available from April 21 via paid Gemini API tiers, the two new research agents are built on Gemini 3.1 Pro (which scores 85.9 on BrowseComp, 25+ points above Gemini 3 Pro). **Deep Research** is optimized for low-latency interactive use; **Deep Research Max** uses extended test-time compute for exhaustive asynchronous workflows (think overnight due-diligence reports). Both agents natively generate charts and infographics, support MCP for connecting to enterprise data sources, and Google is actively collaborating with FactSet, S&P, and PitchBook on MCP server designs.

- **[Google Workspace Studio: No-Code Agent Builder Now Rolling Out](https://workspace.google.com/blog/product-announcements/10-more-announcements-workspace-at-next-2026)** - Announced at Cloud Next, Workspace Studio lets business users build and deploy AI agents across Gmail, Docs, Sheets, Drive, Meet, and Chat by describing automations in plain language (e.g., "every Friday, ping me to update my tracker"). It connects to Asana, Jira, Mailchimp, Salesforce, and custom APIs. A new **Workspace MCP Server** (in preview) enables developer access to Workspace capabilities within external AI agents.

## Developer Tools & Vibe Coding

- **[Cursor 3 Ships: Design Mode, Cloud Agents, Composer 2 Model](https://neuronad.com/cursor-vs-windsurf/)** - Cursor's latest major release (April 2026) adds a dedicated **Agents Window** for parallel task management, **cloud-to-local handoff** (agents run in isolated cloud VMs, triggered from GitHub PRs, Linear, Slack, or the Cursor mobile app), **Design Mode** for visual UI iteration (paint a selection box, describe a change, see code updated in real time), and **Composer 2** — Anysphere's own frontier coding model trained from scratch, scoring 61.3 on CursorBench (39% improvement over Composer 1.5) at 200+ tokens/sec. BugBot, updated April 2026, now learns from PR feedback to promote review rules. Cursor hit $2B ARR in March 2026.

- **[Flat-Rate AI Coding Subscriptions Under Pressure: Claude Code, Copilot, Cursor All Tightening Limits](https://medium.com/activated-thinker/the-flat-rate-ai-coding-subscription-era-is-ending-what-github-copilot-claude-code-and-cursor-9763e043a63a)** - In a six-week window, all three major AI coding tools shifted costs back to heavy users: GitHub Copilot reshaped individual plans and paused some tier signups; Anthropic quietly cut Claude Code's server-side prompt cache TTL from 1 hour to 5 minutes (increasing cache-rebuild costs for long sessions); and Cursor moved frontier models behind Max Mode for legacy Team/Enterprise plans. The common driver: agentic workflows have made per-request costs far higher than flat-rate economics can absorb at scale.

- **[Windsurf (Cognition/Devin) Counter-Moves: SWE-1.5 at 950 tok/s, Free Parallel Agents](https://neuronad.com/windsurf-vs-cursor/)** - Windsurf, now part of Cognition AI (makers of Devin), launched its SWE-1.5 model delivering near-frontier coding quality at 950 tokens/second on Cerebras hardware — roughly 13× faster than Claude Sonnet. The March 2026 pricing update aligned Windsurf Pro at $20/month (matching Cursor), added a $200/month Max tier, and switched from credits to daily/weekly quotas. Windsurf now offers free parallel agents on every plan and supports 40+ IDEs (vs. Cursor's VS Code-only fork), with FedRAMP/HIPAA/ITAR compliance making it the go-to for regulated industries.

- **[Claude Code Annualized Revenue Crosses $2.5B; Holds 42% of Enterprise Coding Workloads](https://fazm.ai/blog/anthropic-april-2026-announcement)** - Despite the subscription controversy this week, Claude Code continues its dominance in enterprise coding: $2.5B+ annualized run rate and 42% enterprise coding workload share, the highest of any AI coding platform, per industry analysis. With Claude Opus 4.7 now powering Code Review — and catching bugs Opus 4.6 missed — the platform's advantage in long-horizon, high-context tasks remains intact.
