# AI Daily Digest - 2026-04-17

## Anthropic

- **[Claude Opus 4.7 Released — Stronger Coding, 3× Vision, New Effort Controls](https://www.cnbc.com/2026/04/16/anthropic-claude-opus-4-7-model-mythos.html)** - Anthropic released Claude Opus 4.7 on April 16, 2026 as its most powerful generally-available model. SWE-bench Verified jumped to 87.6% (from 80.8%), GPQA Diamond hit 94.2%, and high-resolution vision support tripled to 3.75 megapixels. New developer features include a new `xhigh` effort level, `/ultrareview` multi-agent code review command in Claude Code, and Task Budgets in public beta — all at the same $5/$25 per million token price point, available on the API, Bedrock, Vertex AI, and Microsoft Foundry.

- **[Claude Code Desktop App Rebuilt Around Parallel Sessions + Routines Launch](https://venturebeat.com/orchestration/we-tested-anthropics-redesigned-claude-code-desktop-app-and-routines-heres-what-enterprises-should-know)** - On April 14, Anthropic shipped a complete redesign of the Claude Code desktop app featuring a new sidebar for managing multiple parallel sessions, an integrated terminal, in-app file editor, and a rebuilt diff viewer. Alongside the redesign, "Routines" launched in research preview — a way to bundle a prompt, repo, and connectors into a scheduled, API-triggered, or GitHub-event-triggered automation that runs on Anthropic's cloud infrastructure without requiring the user's machine to be on. Available to Pro, Max, Team, and Enterprise users.

## OpenAI

- **[GPT-5.4-Cyber Launched for Vetted Security Defenders](https://openai.com/index/scaling-trusted-access-for-cyber-defense/)** - On April 14, OpenAI unveiled GPT-5.4-Cyber, a fine-tuned variant of GPT-5.4 specifically optimized for defensive cybersecurity work — a direct response to Anthropic's Project Glasswing / Claude Mythos Preview announcement the week prior. The model is "cyber-permissive," lowering refusal thresholds for legitimate security tasks, and adds binary reverse engineering capabilities that let professionals analyze compiled software for vulnerabilities without source-code access. Initial access is limited to vetted security vendors and researchers through OpenAI's expanded Trusted Access for Cyber (TAC) program; OpenAI noted its approach of broader identity-verified access intentionally contrasts with Anthropic's more restrictive ~40-organization rollout.

## Google AI

- **[DeepMind Releases Gemini Robotics-ER 1.6 with Instrument Reading & Boston Dynamics Integration](https://siliconangle.com/2026/04/15/deepmind-launches-gemini-robotics-er-1-6-meet-precise-physical-ai-demands/)** - Google DeepMind launched Gemini Robotics-ER 1.6 on April 14, a significant upgrade to its embodied-reasoning model that acts as the "strategic brain" for physical robots. Key additions include enhanced spatial reasoning, multi-view success detection, and a brand-new instrument-reading capability (pressure gauges, sight glasses) developed with Boston Dynamics — enabling Spot robots to autonomously inspect industrial facilities. The model is available immediately through the Gemini API and Google AI Studio, and Boston Dynamics is already integrating it into Spot's Orbit AIVI-Learning inspection platform.

## Developer Tools & Vibe Coding

- **[Cursor 3 Ships Agent-First Interface with Composer 2 Model](https://cursor.com/blog/cursor-3)** - Cursor launched version 3 (April 2) and its own frontier coding model Composer 2 (March 19), representing the biggest overhaul since the IDE launched. The new interface is built around parallel agent orchestration: all local and cloud agents appear in a unified sidebar, sessions can be seamlessly handed off between local and cloud, and a new plugin marketplace offers 30+ integrations (Atlassian, Datadog, GitLab, Hugging Face). Composer 2 — built on a Kimi K2.5 base with continued pretraining and large-scale RL — scores 61.3 on CursorBench (a 39% jump) and runs at 200+ tokens/sec, priced at $0.50/$2.50 per million tokens.

- **[GitHub Copilot Rolls Out Claude Opus 4.7 for Pro+ Users](https://github.blog/changelog/2026-04-16-claude-opus-4-7-is-generally-available/)** - GitHub Copilot announced on April 16 that Claude Opus 4.7 is now rolling out to Copilot Pro+ subscribers, where it will replace Opus 4.5 and 4.6 in the model picker. Early testing inside Copilot shows stronger multi-step task performance, more reliable agentic execution, and improved long-horizon reasoning on complex, tool-dependent workflows. The model launches with a 7.5× premium request multiplier under promotional pricing through April 30.
