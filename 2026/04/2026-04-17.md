# AI Daily Digest - 2026-04-17

## Anthropic

- **[White House Moves to Give US Agencies Access to Claude Mythos](https://www.reuters.com/technology/white-house-give-us-agencies-anthropic-mythos-access-bloomberg-news-reports-2026-04-16/)** - The White House is actively working to deploy Anthropic's powerful Claude Mythos Preview model across major federal agencies, with OMB federal CIO Gregory Barbaccia sending a memo to Cabinet departments including Defense, Treasury, Commerce, Homeland Security, Justice, and State. Mythos — announced April 7 as part of "Project Glasswing" for defensive cybersecurity — has already found "thousands" of major vulnerabilities in operating systems and web browsers, prompting both alarm and urgent demand from government officials. Anthropic CEO Dario Amodei is reportedly meeting with White House chief of staff Susie Wiles as talks advance despite the ongoing Pentagon supply-chain-risk dispute.

- **[Claude Code Drops Major Update: /ultrareview, Push Notifications & TUI Improvements](https://github.com/anthropics/claude-code/releases)** - Claude Code shipped a broad update featuring `/ultrareview`, a new cloud-based parallel multi-agent command for comprehensive code review (invoke with no arguments to review your current branch, or `/ultrareview <PR#>` for a specific GitHub PR). Also new: `/tui fullscreen` for flicker-free rendering, mobile push notifications when Remote Control is enabled, a `/focus` mode toggle, and an improved `/plugin` installed tab. The release also adds `Claude Opus 4.7 xhigh` effort level, an interactive `/effort` slider, and an "Auto (match terminal)" theme option.

- **[Claude Opus 4.7 Now Generally Available](https://releasebot.io/updates/anthropic)** - Anthropic has released Claude Opus 4.7 as a GA upgrade with stronger software engineering, better vision, sharper instruction following, and more reliable long-running agent work. Opus 4.7 adds new effort controls, task budgets, and Claude Code review tools, and is available across all Claude products, the API, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry at the same pricing as Opus 4.6 ($5/M input, $25/M output tokens).

## OpenAI

- **[OpenAI Launches GPT-Rosalind: First Life Sciences AI Model](https://www.reuters.com/business/healthcare-pharmaceuticals/openai-launches-ai-model-gpt-rosalind-life-sciences-research-2026-04-16/)** - OpenAI unveiled GPT-Rosalind, its first domain-specific model series, named after pioneering chemist Rosalind Franklin and purpose-built for biochemistry, genomics, drug discovery, and translational medicine. The model supports evidence synthesis, hypothesis generation, experimental planning, and multi-step scientific workflows, and outperformed GPT-5.4 on 6 of 11 LABBench2 tasks. It is available as a research preview in ChatGPT, Codex, and the API to vetted enterprise customers including Amgen, Moderna, the Allen Institute, and Thermo Fisher Scientific. OpenAI also launched a free Life Sciences Codex plugin connecting models to 50+ scientific data sources and tools.

- **[OpenAI Codex Gets Major Agentic Update — Direct Shot at Claude Code](https://startupnews.fyi/2026/04/17/openais-big-codex-update-is-a-direct-shot-at-claude-code/)** - OpenAI pushed a major update to Codex positioning it as a direct rival to Anthropic's Claude Code. New features include the ability to operate macOS desktop apps natively on your computer, an in-app browser for web access, image generation, new workplace plug-ins, and persistent memory of useful context across tasks. The companion Agents SDK update adds a model-native harness with configurable memory, native sandbox execution, standardized integrations (MCP, AGENTS.md, skills, shell tools), and portable workspace support with built-in snapshotting for durable agent runs.

- **[GPT-5.4-Cyber Launched for Defensive Cybersecurity](https://www.reuters.com/technology/openai-unveils-gpt-54-cyber-week-after-rivals-announcement-ai-model-2026-04-14/)** - Following Anthropic's Mythos announcement, OpenAI unveiled GPT-5.4-Cyber, a variant of its flagship model fine-tuned specifically for defensive cybersecurity work, rolling out initially to vetted security vendors, organizations, and researchers under its Trusted Access for Cyber program. OpenAI is expanding that program to thousands of verified individual defenders and hundreds of teams protecting critical software.

## Google AI

- **[Google DeepMind Releases Gemini Robotics-ER 1.6 with Instrument Reading & Spatial AI](https://siliconangle.com/2026/04/15/deepmind-launches-gemini-robotics-er-1-6-meet-precise-physical-ai-demands/)** - Google DeepMind released Gemini Robotics-ER 1.6, a significant upgrade to its embodied reasoning model designed as the cognitive "brain" layer for autonomous robots. Key new capabilities include enhanced spatial reasoning, multi-view success detection, and a brand-new instrument reading capability (developed with Boston Dynamics) that lets robots interpret analog pressure gauges and sight glasses in industrial facilities. The model uses agentic vision — combining visual reasoning with code execution — and is available immediately to developers via the Gemini API and Google AI Studio.

- **[Boston Dynamics Integrates Gemini into Spot Robot Inspection Platform](https://roboticsandautomationnews.com/2026/04/15/boston-dynamics-integrates-google-deepminds-gemini-robotics-model-into-spot-inspection-platform/100585/)** - Boston Dynamics has partnered with Google Cloud and Google DeepMind to integrate Gemini and Gemini Robotics-ER 1.6 into its Orbit AIVI-Learning platform powering Spot robots. The integration enables higher-order visual analysis and complex task planning for industrial environments including asset monitoring, safety checks, and materials management. The Gemini-powered AIVI-Learning system is now live for existing platform customers.

## Developer Tools & Vibe Coding

- **[OpenAI Codex Becomes a Full Desktop Agent](https://openai.com/index/codex-for-almost-everything/)** - Today's Codex update (April 16-17) is the biggest signal yet that OpenAI is going head-to-head with Claude Code in the agentic coding space. The new version can operate macOS desktop apps, browse the web inside the app, generate images, use workplace plug-ins, and remember context from past sessions — moving well beyond terminal-based code generation into full computer-use territory. Alongside this, OpenAI's updated Agents SDK now includes Codex-like filesystem tools, sandbox-aware orchestration, MCP tool use, skills via progressive disclosure, and custom instructions via AGENTS.md.

- **[Claude Code /ultrareview Brings Cloud-Parallel Code Review to the CLI](https://github.com/anthropics/claude-code/releases)** - Claude Code's new `/ultrareview` command runs comprehensive code review in the cloud using parallel multi-agent analysis and critique — a meaningful upgrade for teams doing async review workflows. Invoke with no arguments to review your current branch, or point it at a specific PR number. Combined with the new `/less-permission-prompts` skill (which auto-generates allowlists for read-only Bash/MCP tool calls) and Opus 4.7 xhigh effort mode, Claude Code continues to expand its lead as the terminal-first agentic coding platform.

- **[Claude Code Holds 46% "Most Loved" Developer Rating vs. Cursor at 19%](https://dev.to/alexcloudstar/claude-code-vs-cursor-vs-github-copilot-the-2026-ai-coding-tool-showdown-53n4)** - A 2026 developer survey found Claude Code — launched in May 2025 — has achieved a 46% "most loved" rating among developers surveyed, compared to Cursor at 19% and GitHub Copilot at 9%. The vibe coding landscape has settled into clear lanes: Claude Code for large agentic/autonomous tasks, Cursor for deep IDE-native daily flow, and Copilot for inline acceleration within existing editors. Experienced developers now use an average of 2.3 tools, treating them as complementary rather than competing.

- **[OpenAI GPT-Rosalind Life Sciences Codex Plugin Ships with 50+ Data Sources](https://www.axios.com/2026/04/16/openai-models-life-sciences-drugs)** - Alongside GPT-Rosalind, OpenAI launched a free Life Sciences research plugin for Codex that hooks models into 50+ scientific databases and computational pipelines including human genetics, functional genomics, protein structure, and clinical evidence sources. This is a significant developer-facing move for biotech and research engineers building AI-assisted scientific workflows, giving programmatic Codex access to datasets that previously required bespoke integrations.
