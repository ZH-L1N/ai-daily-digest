# AI Daily Digest - 2026-04-23

## Anthropic

- **[Anthropic Investigates Unauthorized Access to Claude Mythos](https://techcrunch.com/2026/04/21/unauthorized-group-has-gained-access-to-anthropics-exclusive-cyber-tool-mythos-report-claims/)** - Anthropic confirmed it is investigating a report that a small group of users gained unauthorized access to Claude Mythos Preview — the restricted cybersecurity model released only to a handful of trusted partners (Amazon, Apple, Cisco, JPMorgan Chase, Nvidia) under Project Glasswing. The group reportedly accessed the model through a third-party vendor environment by guessing its API endpoint on the day of its public announcement. Anthropic says there is no evidence its own systems were impacted beyond the vendor environment.

- **[Claude Code v2.1.118 Ships (April 23)](https://code.claude.com/docs/en/changelog)** - The latest Claude Code release (first seen April 23) adds vim visual mode (`v` and `V`) with selection and operators, fixes an issue where the same message could appear at two positions when scrolling up in fullscreen mode, improves Write tool diff computation speed by 60% for large files, and fixes several MCP and session bugs. It also adds MCP tool result persistence override (up to 500K chars) for larger results like DB schemas.

- **[Anthropic Tests Removing Claude Code from Pro Plan — Then Reverses](https://www.theregister.com/2026/04/22/anthropic_removes_claude_code_pro/)** - On April 22, Anthropic's pricing page briefly showed Claude Code removed from the $20/month Pro plan, appearing only on the $100/$200 Max plans — sparking developer backlash on Reddit, Hacker News, and X. Anthropic's head of growth clarified it was "a small test on ~2% of new prosumer signups" and reverted the landing page and docs changes. The incident highlights Anthropic's tensions around monetizing agentic features as usage per subscriber climbs.

## OpenAI

- **[ChatGPT Images 2.0 (gpt-image-2) Launches](https://openai.com/index/introducing-chatgpt-images-2-0/)** - OpenAI launched ChatGPT Images 2.0 on April 21, powered by the new `gpt-image-2` model — the first image model with native O-series reasoning capabilities. It supports 2K resolution, can generate up to eight coherent images from a single prompt with character and object consistency, renders accurate multilingual text (including CJK, Hindi, Bengali, Arabic), and integrates web search before generating. It immediately took a +242-point lead on the Image Arena leaderboard; Thinking Mode requires ChatGPT Plus/Pro/Business, while Instant Mode is free. The API opens to developers in early May; DALL-E 2 and DALL-E 3 retire May 12.

- **[OpenAI Launches Codex Labs and Enterprise Partner Network](https://openai.com/index/scaling-codex-to-enterprises-worldwide/)** - OpenAI announced Codex Labs — a hands-on consulting program bringing OpenAI experts into enterprises to deploy Codex — alongside a formal GSI partner network including Accenture, Capgemini, CGI, Cognizant, Infosys, PwC, and TCS. Weekly active Codex users hit 4 million (up from 3 million just two weeks prior), and within ChatGPT Business/Enterprise, Codex users grew 6x between January and April. Enterprise revenue now accounts for more than 40% of OpenAI's total revenue.

## Google AI

- **[Google Launches Deep Research & Deep Research Max on Gemini 3.1 Pro](https://blog.google/innovation-and-ai/models-and-research/gemini-models/next-generation-gemini-deep-research/)** - Google released two new autonomous research agents via the Gemini API on April 21–22: **Deep Research** (optimized for speed, lower latency and cost) and **Deep Research Max** (extended test-time compute for maximum synthesis depth). Both are built on Gemini 3.1 Pro and support MCP for secure access to proprietary enterprise data alongside the public web. They natively generate charts and infographics (HTML or Nano Banana), support multimodal input (PDFs, CSVs, video), and integrate with financial data providers FactSet, S&P Global, and PitchBook. Deep Research Max scores 93.3% on DeepSearchQA (up from 66.1% in December) and 54.6% on Humanity's Last Exam. Both are available in public preview on paid Gemini API tiers.

## Developer Tools & Vibe Coding

- **[SpaceX Secures $60B Option to Acquire Cursor AI](https://techcrunch.com/2026/04/21/spacex-is-working-with-cursor-and-has-an-option-to-buy-the-startup-for-60-billion/)** - In the biggest developer-tools deal of the year, SpaceX announced a partnership with Cursor that includes the right to acquire the AI coding startup for $60 billion later in 2026 (post-IPO) or pay $10 billion for joint development. The deal pairs Cursor's leading developer distribution with SpaceX's Colossus supercomputer (equivalent to 1 million Nvidia H100s, via its xAI merger). Cursor confirmed the partnership will "dramatically scale up the intelligence of our models" after being "bottlenecked by compute." The deal preempted a $2B fundraise at a $50B valuation that Cursor was days away from closing with Andreessen Horowitz, Nvidia, and Thrive. Microsoft had previously evaluated acquiring Cursor but passed.

- **[Claude Code Pricing Controversy Highlights Agentic Tool Monetization Shift](https://simonwillison.net/2026/Apr/22/claude-code-confusion/)** - The brief removal of Claude Code from Anthropic's $20/month Pro plan (see Anthropic section) sent ripples through the vibe-coding community — Claude Code has become a core part of many developers' workflows, with deep integration across VS Code, Cursor, and Windsurf terminals. Anthropic's head of growth noted that usage patterns have "changed fundamentally" since Max launched, with long-running async agents and Cowork now everyday workflows, suggesting plan restructuring may still be on the horizon.
