# AI Daily Digest - 2026-04-18

## Anthropic

- **[Claude Design Launches: AI-Powered Visual Prototyping for Teams](https://techcrunch.com/2026/04/17/anthropic-launches-claude-design-a-new-product-for-creating-quick-visuals/)** - Anthropic launched Claude Design on April 17, a new experimental product that lets users create prototypes, slides, one-pagers, and other visuals from plain-text prompts. Powered by Opus 4.7, Claude Design onboards teams by reading their codebase and design files to auto-generate a reusable design system; outputs can be exported as PDFs, URLs, PPTX files, or sent directly to Canva for collaborative editing. It is available in research preview for Pro, Max, Team, and Enterprise subscribers and is Anthropic's latest bid to expand into the prosumer and enterprise design space without requiring a design background.

- **[Claude Code Gets Opus 4.7 xhigh Effort, Auto Mode, and /ultrareview](https://releasebot.io/updates/anthropic/claude-code)** - The April 17 Claude Code release adds a new `xhigh` effort level for Opus 4.7 — sitting between `high` and `max` — accessible via `/effort`, `--effort`, or the model picker. Auto mode (which lets the model self-select effort) is now available to Max subscribers using Opus 4.7, and the new `/ultrareview` command triggers a multi-agent code review pass. The update also reduces unnecessary permission prompts, improves Windows support (drive-letter path anchoring, `CLAUDE_ENV_FILE` now applied correctly), and fixes a batch of editor, terminal, and MCP reliability issues.

## OpenAI

- **[Codex for (Almost) Everything: Computer Use, SSH Devboxes, Image Gen & 90+ Plugins](https://openai.com/news/)** - In a product update published April 16, OpenAI repositioned Codex from a coding tool into a broad software-work operating environment. New capabilities include background computer use on macOS (Codex can see, click, and type with its own cursor while you work in other apps), an in-app browser for fast frontend iteration, native image generation, persistent memory/preferences, long-running automations, SSH access to remote devboxes (alpha), and 90+ new plugin integrations. Deeper developer features cover PR review, multiple terminal tabs, richer file previews, and an integrated Atlas browser for inline design feedback — a direct response to the fact that 50% of Codex users were already giving it non-coding tasks.

- **[GPT-Rosalind Introduced: Frontier Reasoning for Life Sciences](https://openai.com/news/)** - Also on April 16, OpenAI introduced GPT-Rosalind, a research-preview reasoning model purpose-built for biology, drug discovery, and translational medicine. The model pairs improved tool use with deeper scientific understanding across chemistry, protein engineering, and genomics, and is accompanied by a Codex research plugin that connects scientists to 50+ data sources and tools. Partners including Amgen are already evaluating it for accelerating drug-development workflows.

## Google AI

- **[Gemini Robotics-ER 1.6 Now Available via API, Powers Boston Dynamics Spot](https://siliconangle.com/2026/04/15/deepmind-launches-gemini-robotics-er-1-6-meet-precise-physical-ai-demands/)** - Google DeepMind's Gemini Robotics-ER 1.6 became publicly available through the Gemini API and Google AI Studio this week. The model combines visual reasoning with code execution ("agentic vision") for precise instrument reading — pressure gauges, sight glasses — and adds enhanced spatial reasoning and multi-view success detection. Boston Dynamics is already integrating it into Spot's Orbit AIVI and AIVI-Learning inspection systems, enabling the robot to move beyond basic object recognition into higher-order reasoning about industrial facilities.

- **[Gemini 3.1 Flash TTS: Direction-Based AI Voice with 70+ Languages](https://www.buildfastwithai.com/blogs/gemini-3-1-flash-tts-google-ai-voice-model-2026)** - Launched April 15, Gemini 3.1 Flash TTS introduces "audio tags" — natural-language stage directions embedded in text (e.g. `[excited]`, `[pause]`) — that control vocal style, pacing, and emotional delivery, supporting 200+ tags across 70+ languages and 30 distinct voices with native multi-speaker dialogue. Google has repositioned TTS away from text-to-speech conversion and toward "AI vocal performance." The model is in public preview via Google AI Studio (free tier), the Gemini API, and Vertex AI under the model ID `gemini-3.1-flash-tts-preview`.

## Developer Tools & Vibe Coding

- **[GitHub Copilot CLI v1.0.28: Claude Opus 4.7 Support + MCP & CI Improvements](https://github.com/github/copilot-cli/releases)** - Released April 16, GitHub Copilot CLI v1.0.28 adds first-class support for Claude Opus 4.7, a new `--list-env` flag that logs all loaded plugins, agents, skills, and MCP servers in CI pipelines, and a fix allowing remote MCP server configs to omit the `type` field (defaulting to `http`). The release also patches repository-owner detection from git remote URLs (rather than local usernames), fixes Windows crash-exit terminal restoration, and stabilizes the blinking cursor width to prevent text shift.

- **[GitHub CLI Adds `gh skill` Command for Cross-Tool Agent Skill Management](https://github.blog/changelog/2026-04-16-manage-agent-skills-with-github-cli/)** - GitHub shipped `gh skill` in the GitHub CLI (v2.90.0+) on April 16, giving developers a package-manager-style interface for browsing, previewing, installing, pinning, updating, and publishing Agent Skills. Skills work across GitHub Copilot, Claude Code, Cursor, OpenAI Codex, and Gemini CLI via the open Agent Skills spec. The `gh skill publish` command validates skills against the agentskills.io spec and audits supply-chain security settings (tag protection, secret scanning, immutable releases) before publishing.
