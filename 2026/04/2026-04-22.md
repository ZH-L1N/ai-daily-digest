# AI Daily Digest - 2026-04-22

## Anthropic

- **[Claude Code Broad Polish & Reliability Update](https://releasebot.io/updates/anthropic/claude-code)** - Anthropic shipped a wide-ranging reliability update to Claude Code (first seen Apr 21), making `/resume` up to 67% faster on large sessions (40MB+) and improving handling of sessions with many dead-fork entries. The update also brings quicker MCP startup when multiple stdio servers are configured, inline thinking progress ("still thinking" / "almost done thinking"), and smoother fullscreen scrolling in VS Code, Cursor, and Windsurf terminals via `/terminal-setup`.

- **[Introducing Claude Opus 4.7](https://www.anthropic.com/news/claude-opus-4-7)** - Anthropic released Claude Opus 4.7 (Apr 16), its most capable publicly-available model, featuring stronger software engineering, better long-running agentic tasks, and higher-resolution vision. The model is available across Claude products, the API, Amazon Bedrock, Google Cloud Vertex AI, and Microsoft Foundry at the same price as Opus 4.6 ($5/M input, $25/M output tokens). Early testers report a 13% lift on coding benchmarks over Opus 4.6 and describe it as the first model capable of handling the "hardest coding work" without close supervision.

- **[Introducing Claude Design by Anthropic Labs](https://www.anthropic.com/news/claude-design-anthropic-labs)** - Anthropic launched Claude Design (Apr 17), a new Labs product that lets users collaborate with Claude to produce polished visual work — prototypes, slides, one-pagers, and more — without starting from a design tool. Teams can apply their existing design systems and codebases to ensure brand consistency, then export outputs as PDFs, URLs, PPTX files, or send them directly to Canva for further editing. Anthropic frames Claude Design as complementing — not replacing — dedicated design apps.

## OpenAI

- **[OpenAI Leans on Global Consultancies to Expand Codex Enterprise Adoption](https://www.reuters.com/business/openai-leans-global-consultancies-expand-codex-use-large-companies-2026-04-21/)** - Reuters reported (Apr 21) that OpenAI is formalizing partnerships with Accenture, Capgemini, CGI, Cognizant, Infosys, PwC, and Tata Consultancy Services to accelerate Codex adoption inside large enterprises, and is launching "Codex Labs" — placing OpenAI specialists directly inside customer organizations. Weekly Codex usage has jumped to over 4 million developers, up from around 3 million earlier this month, reflecting rapid enterprise momentum.

- **[Codex for (Almost) Everything — Major Feature Expansion](https://openai.com/index/codex-for-almost-everything/)** - OpenAI shipped a landmark update to Codex (Apr 16) repositioning it from a coding agent into a full AI developer workstation. Key additions include background computer use (macOS, multiple parallel agents), an in-app browser for frontend iteration, image generation via gpt-image-1.5, a memory preview that retains preferences and project conventions, 90+ new plugins including Atlassian Rovo, CircleCI, GitLab Issues, and Microsoft Suite, plus GitHub PR review, multiple terminal tabs, and SSH devbox connections in alpha. Personalization and computer use features are rolling out to EU/UK and Enterprise users soon.

- **[Codex Standalone Installer & TUI Improvements (Apr 21 Build)](https://releasebot.io/updates/openai/codex)** - The latest Codex build (seen Apr 21) ships a more self-contained standalone installer, fixes Windows and Intel Mac setup issues, adds richer TUI side conversations (`/side`), stronger Plan Mode workflows with context-usage visibility, tabbed plugin browsing with inline enable/disable toggles, and tighter filesystem sandbox controls including deny-read glob policies.

## Google AI

- **[Gemini 3 Deep Think Major Upgrade — Now Available via API](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-deep-think/)** - Google released a major upgrade to Gemini 3 Deep Think (Apr 15), its specialized reasoning mode targeting science, research, and engineering. Google AI Ultra subscribers can access the updated Deep Think in the Gemini app; for the first time, it is also being made available via the Gemini API to select researchers, engineers, and enterprises. The upgraded mode achieves gold medal-level results on the 2025 International Physics and Chemistry Olympiad written sections, and scores 41.0% on Humanity's Last Exam (without tools) and 93.8% on GPQA Diamond.

- **[Gemini Robotics-ER 1.6 Released](https://theaiinsider.tech/2026/04/15/google-deepmind-releases-newest-gemini-robotics-reasoning-model-designed-to-improve-how-robots-interpret-and-act-in-real-world/)** - Google DeepMind released Gemini Robotics-ER 1.6, an updated robotics reasoning model with new capabilities including instrument reading, improved spatial and physical reasoning, multi-view perception, and better task-completion detection. The model shows +6% improvement in text and +10% improvement in video for injury risk perception over baseline Gemini 3.0 Flash, and is now available via the Gemini API and Google AI Studio. Boston Dynamics' Spot robot is among the first integrations.

- **[Google Antigravity — New Agentic Development Platform](https://blog.google/products/gemini/gemini-3/)** - Launched alongside Gemini 3, Google Antigravity is Google's new agentic IDE that gives agents direct, autonomous access to the editor, terminal, and browser. Powered by Gemini 3 Pro, Gemini 2.5 Computer Use for browser control, and Nano Banana (Gemini 2.5 Image) for image editing, agents can plan and execute complex end-to-end software tasks while validating their own code. The platform is available now and Gemini 3 is also accessible via Cursor, GitHub, JetBrains, Replit, and more.

## Developer Tools & Vibe Coding

- **[Cursor 3 Ships Design Mode, Agents Window & Cloud-to-Local Handoff](https://neuronad.com/cursor-vs-windsurf/)** - Cursor 3 (April 2026) ships a dedicated Agents Window for parallel background cloud agents, cloud-to-local handoff, Design Mode for visual UI iteration, and Composer 2 — Cursor's own frontier coding model running at 200+ tokens/sec. Cursor has now reached $2 billion ARR and is valued at up to $60 billion; according to a JetBrains January 2026 developer survey, Cursor holds 18% workplace adoption, tied with Claude Code, with GitHub Copilot still leading at 29%.

- **[Windsurf (Cognition/Devin) Counters with SWE-1.5 at 950 tok/s & Free Parallel Agents](https://neuronad.com/cursor-vs-windsurf/)** - Windsurf, now owned by Cognition AI (the team behind Devin), ships SWE-1.5 running at 950 tokens/sec on Cerebras hardware, Cascade Hooks for workflow automation, and free parallel agents on every plan. In March 2026, Windsurf removed all quota restrictions on tab completions across all plans. Both Cursor Pro and Windsurf Pro are now $20/month; Windsurf supports 40+ IDEs versus Cursor's VS Code-only approach and holds SOC 2, HIPAA, FedRAMP, and ITAR certifications.

- **[OpenAI GPT-Rosalind — Life Sciences Reasoning Model](https://openai.com/news/)** - OpenAI introduced GPT-Rosalind (Apr 16/17), its first frontier reasoning model built specifically for biology, drug discovery, and translational medicine. Paired with a new Codex research plugin connecting scientists to 50+ tools and data sources, it is designed to accelerate workflows from target discovery through clinical research — a domain where the average drug takes 10–15 years from discovery to approval.
